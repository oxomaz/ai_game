## ⚡ 연산 스피드 퀴즈 — `games/study/math-speed/`

제한 시간 안에 사칙연산 문제를 **최대한 많이** 푸는 게임입니다.

- **연산 고르기** — 덧셈 · 뺄셈 · 곱셈 · 나눗셈을 원하는 대로 조합 (여러 개 동시 선택 가능)
- **난이도 3단계** — 쉬움(10 이내 덧셈 · 2~5단) / 보통(두 자리 덧뺄셈 · 구구단) / 어려움(세 자리 덧뺄셈 · 두 자리 곱셈)
- **나눗셈은 항상 딱 나누어떨어지고**, 뺄셈 결과가 음수가 되지 않게 출제됩니다.
- 시간 30 / 60 / 120초 선택. 오답이면 **−3초**, 연속 정답이면 최대 **+20점 보너스**
- 정답 자릿수만큼 입력하면 **자동 채점** — 확인 버튼 없이 술술 넘어갑니다.
- 끝나면 틀린 문제를 정답과 함께 모아 보여주고, (연산 조합 · 난이도 · 시간)별로 최고 기록을 남깁니다.

**조작** — 화면 숫자 키패드 터치 (PC는 숫자키 · `Enter` · `Backspace`)

자세한 설명은 [`games/study/math-speed/README.md`](games/study/math-speed/) 참고.

## 🚀 구구단 슈팅 — `games/study/times-table-shooter/`

화면 위에서 내려오는 숫자 풍선 중 **정답을 골라 쏘는** 액션 게임입니다.

- **연습할 단을 직접 고릅니다** — 2단부터 9단까지, 여러 개 동시 선택 가능
- 오답 보기는 `7×8`의 오답으로 `7×7`, `8×8` 같은 **한 칸 옆 구구단 값**을 주로 뽑아, 찍어서는 맞히기 어렵습니다.
- 목숨 3개. 오답을 쏘거나 정답 풍선을 놓치면 하나 줄어듭니다.
- 5개 맞힐 때마다 **단계 상승** — 풍선이 조금씩 빨라집니다. 속도 3단계 선택.
- 게임이 끝나면 **자주 틀린 구구단**을 횟수와 함께 모아 보여줍니다.

**조작** — 풍선 터치 / 클릭

자세한 설명은 [`games/study/times-table-shooter/README.md`](games/study/times-table-shooter/) 참고.

## 🔤 영단어 카드 퀴즈 — `games/study/word-cards/`

초등 3학년 수준 영단어 **120개**를 외우고 확인하는 게임입니다.

- **주제 8가지 × 각 15개** — 동물 · 음식 · 학교 · 몸과 감정 · 색과 숫자 · 집과 물건 · 자연과 날씨 · 동작
- **방식 3가지** — 📇 카드 외우기 / 영어 → 뜻 4지선다 / 뜻 → 영어 4지선다
- 오답 보기를 **같은 주제 안에서** 뽑아, 주제가 달라서 찍어 맞히는 일이 없습니다.
- 🔊 **발음 듣기** 지원 (브라우저 음성 기능. 안 되는 기기에서는 조용히 무시됩니다)
- 끝나면 **틀린 단어만 골라 다시** 풀 수 있습니다.
- 단어 추가는 `index.html` 맨 위 `WORDS` 목록에 `["단어","뜻"]` 한 줄이면 끝입니다.

**조작** — 카드 / 보기 터치 · 클릭

자세한 설명은 [`games/study/word-cards/README.md`](games/study/word-cards/) 참고.

## 🧠 상식·과학 퀴즈 — `games/study/quiz-science/`

O/X와 4지선다가 섞인 상식 퀴즈입니다. **문제마다 왜 그런지 해설**이 나옵니다.

- **주제 6가지 · 총 43문제** — 과학(10) · 우주(7) · 동물과 자연(7) · 한국과 사회(7) · 역사(5) · 생활상식(7)
- 맞히든 틀리든 **해설 카드**가 열려서, 틀린 문제를 그냥 넘어가지 않습니다.
- O/X 문제는 자동으로 크게 두 칸으로 표시되고, 4지선다는 매번 보기 순서가 섞입니다.
- 연속 정답 보너스, 정확도에 따른 메달(🥉🥈🥇🏆)
- 끝나면 **틀린 문제만 다시** 풀 수 있습니다.
- 문제 추가는 `index.html` 맨 위 `BANK` 목록에 `{q, a, c, e}` 한 줄이면 끝입니다.

**조작** — 보기 터치 · 클릭

자세한 설명은 [`games/study/quiz-science/README.md`](games/study/quiz-science/) 참고.

## 🔤 끝말잇기 — `games/fun/word-chain/`

앞사람이 말한 단어의 **마지막 글자로 시작하는 단어**를 이어 말하는 고전 게임입니다.

- **컴퓨터와 대결** — 쉬움 / 보통 / 어려움 3단계. 난이도가 올라갈수록 컴퓨터가 더 어려운 글자를 남깁니다.
- **여러 명이서 함께** — 최대 8명까지 이름을 입력하고 한 화면에서 순서대로. 순서 랜덤 섞기 지원.
- 한 턴 **15초 제한** 또는 시간 제한 없는 **자유 모드** 선택.
- 내장 한국어 사전으로 실제 단어인지 판정하며, "사전에 없는 단어도 허용" 옵션으로 느슨하게 즐길 수도 있습니다.
- 먼저 시작하는 사람(나 / 컴퓨터 / 랜덤)을 고를 수 있고, 이어진 단어 수가 기록됩니다.

**조작** — 키보드로 단어 입력 후 Enter

## 🌐 친구랑 온라인 대결 (게임 9종 공통)

**게임 9개 모두** 시작 화면의 **🌐 친구랑 온라인 대결** 버튼으로 멀리 있는 친구와 겨룰 수 있다.

1. 한 명이 **방 만들기** → 4글자 **방 코드**가 나온다
2. 친구가 같은 게임을 열고 **방 참여하기** → 코드 입력
3. 방장이 **대결 시작!** → 둘 다 똑같은 문제/맵으로 동시에 시작
4. 화면 위 **VS 바**에 서로의 점수가 실시간으로 보이고, 둘 다 끝나면 승패 화면이 뜬다

별도 서버는 없다. 브라우저끼리 직접 연결(WebRTC P2P)하고 연결 중개만 PeerJS 공개 서버를 쓴다. 공용 코드는 `common/versus.js` 한 파일이며, 새 게임에도 같은 방식으로 붙일 수 있다.

## 🔍 숨은그림찾기 — `games/fun/hidden-object/`

수십 개의 귀여운 그림이 흩뿌려진 그림판에서 **위에 제시된 목표 그림**을 찾아 클릭하는 게임입니다.
34종의 일러스트를 코드로 직접 그리기 때문에, **매판 위치·크기·회전·색이 새로 생성**되어 같은 판이 두 번 나오지 않습니다.

- **혼자 하기** — 제한시간 안에 목표를 모두 찾으면 클리어. 남은 시간 × 5점이 보너스로 붙습니다.
  틀리면 −20점 −3초, 힌트는 라운드당 1번(−40점).
- **둘이서 대결** — 같은 화면을 함께 보다가, 찾은 사람이 **먼저 버저를 누르고** 4초 안에 그림을 클릭합니다.
  - 1P `Q` · 2P `P` (모바일·태블릿은 화면 아래 버저 버튼)
  - 정답 +100점 / 오답 −40점 / 시간 초과 −20점, 실패하면 2.5초간 버저 잠금
  - 마우스 하나로도 두 명이 제대로 대결할 수 있게 만든 방식입니다.
- **난이도 4단계** — 쉬움(30개) · 보통(58개) · 어려움(95개) · 악몽(140개). 위로 갈수록 그림이 작아지고 많이 회전하며, 색 변화도 커집니다.
- 라운드 수 3 / 5 / 7판 선택, 라운드마다 배경 테마가 바뀝니다.

**조작** — 마우스 클릭 또는 터치 / 대결 버저 `Q` `P` / 힌트 `H` / 나가기 `Esc`

## 🃏 SET 카드게임 — `games/fun/set/`

색깔·모양·개수·무늬 네 가지 속성을 가진 카드 12장 중, **각 속성이 "셋 다 같거나 셋 다 다른"** 조합 세 장을 찾아내는 두뇌 게임입니다.

- 게임을 처음 접해도 되도록 **규칙 설명 + 연습 문제**부터 시작합니다. ("이 세 장은 SET일까요?" ⭕ / ❌)
- **혼자 연습** — 찾은 SET 개수와 걸린 시간을 기록.
- **2인 대결** — 각자 자기 이름 버튼을 누른 뒤 세 장을 고르는 방식으로 한 화면에서 대결.
- 더 찾을 SET이 없으면 "SET 없어요"를 선언해 다음 카드로 넘어갑니다.
- 힌트 기능과 사용 횟수 표시 지원.

**조작** — 카드 세 장 클릭 / 터치

## 🏃 점프맵 200 — `games/fun/jump-map/`

발판을 밟고 뛰어올라 목표 지점에 도달하는 **200단계 파쿠르 점프맵**입니다.
레벨이 올라갈수록 발판이 좁아지고 간격이 멀어지며, 새 장애물이 하나씩 추가됩니다.

- **닉네임 프로필** — 한 컴퓨터에서 여러 명이 각자 닉네임을 만들어 따로 플레이하고, **기록실**에서 순위를 겨룹니다.
- **캐릭터 12종** — 네모 · 고양이 · 개구리 · 로봇 · 유령 · 펭귄 · 병아리 · 공룡 · 닌자 · 마법사 · 슬라임 · 별똥별.
- **별 3개 수집** — 레벨마다 숨은 별 3개. 안 먹어도 클리어는 되지만 기록에 남습니다.
- 발판 7종(이동 · 컨베이어 · 부서짐 · 트램폴린 · 점멸 · 얼음)과 장애물 7종(가시 · 튀어나오는 가시 · 톱날 · 레이저 · 회전 가시봉 · 대포 · 추격 가시벽)이 레벨에 따라 등장합니다.
- 긴 레벨에는 **체크포인트 깃발**이 있어 죽어도 그 지점부터 다시 시작합니다.
- 모바일에서는 화면 아래 방향·점프 버튼으로 조작하며, 가로 화면을 권장합니다.

**조작** — `←` `→` 이동 · `Space` 점프 · `R` 재시작 · `ESC` 레벨 목록 (모바일은 화면 버튼)

자세한 설명은 [`games/fun/jump-map/README.md`](games/fun/jump-map/) 참고.

## 🚇 지하철 슬리더 — `games/fun/subway-io/`

승객을 태워 편성을 늘리고, 다른 열차와 부딪히지 않게 피해 다니는 **slither.io 방식의 지하철 게임**입니다.
지렁이 대신 지하철 열차가 달리고, 몸통이 길어질수록 편성 칸수가 늘어납니다.

- **내 열차 고르기** — 시작 전 두 단계로 정합니다.
  - **노선 18종** — 1~9호선 · 신분당선 · 공항철도 · 경의중앙선 · 수인분당선 · 우이신설선 · GTX-A · 인천1호선 · 부산1호선 · 대구1호선 (실제 노선색 그대로)
  - **등급 7종** — 일반 · 급행(사선 띠) · 특급(두 줄 라인) · ITX-새마을(큰 창·붉은 벨트) · KTX(유선형 앞머리) · 무궁화호(작은 창·크림 띠) · 광역급행(쐐기형 전면부)
  - 등급은 **겉모습만** 다릅니다. 속도·회전력·성장 속도는 7종 모두 동일해서 유불리가 없습니다.
- **규칙** — 승객 5명당 1칸씩 늘어나며(4칸 → 최대 44칸), 내 머리가 남의 차량에 닿으면 탈선. 반대로 상대가 내 몸통에 부딪히면 그 열차가 태우던 승객이 선로에 쏟아집니다. 자기 몸통에는 부딪히지 않습니다.
- **편성이 길수록 회전이 무거워집니다.** 짧을 때처럼 급하게 꺾이지 않으니 미리 돌기 시작해야 합니다.

## 🍳 요리조리 셰프 — `games/fun/cooking-catch/`

- **레시피 24가지 · 재료 28가지** — 김밥 · 비빔밥 · 카레라이스 · 초밥 · 김치찌개 · 햄버거 · 피자 · 파스타 · 팬케이크 · 샐러드 · 타코 · 스테이크 등. 같은 요리가 연달아 나오지 않습니다.
- **규칙** — 레시피에 있는 재료를 받으면 `+5점`(연속으로 받으면 최대 `+10점`), 재료를 다 모으면 요리 완성으로 `30점 + 재료 수 × 5점`. 레시피에 없는 재료는 `-3점`, 🪰 🧦 🪨 같은 이상한 것을 받으면 하트가 하나 사라집니다(하트 3개).
- **난이도 3단계** — 쉬움(재료 3개 · 느림) · 보통 · 어려움. 요리를 완성할수록 재료가 점점 빨라집니다.
- **🌐 친구랑 온라인 대결** — 방 코드로 연결하면 **똑같은 요리가 똑같은 순서로** 나옵니다. 60초 동안 더 많이 요리한 사람이 승리. (대결 중에는 일시정지가 없습니다.)
- 기록은 난이도별로 따로 쌓이고, 온라인 순위표에는 **보통 · 60초** 판만 올라갑니다. 배지 5종.

**조작** — 화면을 좌우로 끌기(터치·마우스) 또는 `←` `→`/`A` `D` 키, `Space`·`P` 로 잠깐 멈춤

## 👑 달무티 — `games/fun/dalmuti/`

리처드 가필드의 보드게임 **The Great Dalmuti**를 규칙 그대로 옮긴 카드 게임입니다. **2~10명**.

- **카드 80장** — 숫자 n은 딱 n장씩(1은 1장 … 12는 12장) + 광대 2장. 숫자가 **작을수록 강합니다.**
- **계급** — 대달무티 · 소달무티 · 상인 · 소농노 · 대농노. 먼저 손을 터는 순서대로 다음 판 계급이 정해집니다.
- **세금** — 대농노는 가장 좋은 카드 2장을 대달무티에게, 대달무티는 아무 카드 2장을 돌려줍니다. 소농노↔소달무티는 1장.
- **혁명 / 대혁명** — 광대 2장을 다 가진 사람은 세금을 없앨 수 있고, **대농노가 선언하면 계급이 통째로 뒤집힙니다.**
- **광대** — 다른 숫자와 같이 내면 그 숫자가 되고, 혼자 내면 13(가장 약함)입니다.
- **패스 규칙** — 원작(패스해도 다시 낼 수 있음) / 변형(한 번 패스하면 그 판은 쉼) 중에 고를 수 있습니다.
- **온라인** — 방 코드 4글자로 최대 10명. 빈 자리는 컴퓨터가 채우고, 중간에 나간 사람 자리도 컴퓨터가 이어받습니다.
- 컴퓨터 실력 3단계, 3·5·10·20판 중 선택. 순위표에는 **4명 · 보통 · 5판**만 올라갑니다. 배지 5종.

- **카드팩 파일만 넣으면 새 주제가 생깁니다.** `packs/<이름>.js` 하나 + `index.html` 에 `<script>` 한 줄.

## 🌳 Tiny World — `games/fun/tiny-world/`

황량한 섬을 돌아다니며 자원을 모아 도구와 건물을 만들고, 귀여운 정령을 친구로 만들어 **세계수를 4단계까지 키우는** 탐험·채집·제작·건설 게임입니다. (8~11살)

- **섬 24×30 타일** — 시작 평원(처음부터) / 작은 숲(세계수 2단계) / 바위 언덕(3단계) / 별빛 해안(4단계). 잠긴 지역은 안개로 가려집니다.
- **채집 → 제작 → 건설 → 퀘스트 → 성장 → 세계수 → 새 지역**이 끊기지 않게 이어집니다. 퀘스트 22개가 순서대로 열리고 한 번에 3개만 보여 줍니다.
- **정령 4종** — 🍃 잎새 / 🪨 돌멩이 / 💧 물방울 / 🔥 불씨. **확률형 뽑기가 없습니다.** 조건을 채우면 맵에 나타나고, 말을 걸어 선물을 주면 친구가 됩니다. 건물에 배치해 일을 맡길 수도 있습니다.
- **건물 5종** — 작업대 · 작은 집 · 텃밭 · 창고 · 정령 쉼터. 모두 진짜 기능이 있고, 복잡한 블록 쌓기 대신 **빈 타일을 골라 놓는** 쉬운 방식입니다.
- **전투 · 결제 · 광고 · 채팅 · 로그인이 없습니다.** 자원을 전부 잃거나 처음부터 다시 하는 시스템도 없습니다.
- 그림은 외부 이미지 없이 캔버스로 직접 그린 오리지널 아트이고, 효과음은 Web Audio 합성입니다. 진행은 10초마다 자동 저장됩니다.
- 시작 화면에서 **플레이어**를 고르면 사람마다 기록·배지가 따로 쌓입니다. 섬 점수(세계수 단계 · 레벨 · 정령 · 건물 · 퀘스트 · 도감)로 내 최고 기록이 남고, **온라인 순위표는 쓰지 않습니다**(남과 겨루는 게임이 아니라 내 섬을 키우는 게임이라서요). 배지 6종.
- 막혔을 때는 화면 위 **❓ 버튼**(또는 지금 할 일 칸의 ❓)을 누르면 도움말이 열립니다. 지금 할 일을 풀어서 설명하고, **🧭 길안내 화살표**로 목표 위치를 지도에 표시해 줍니다. 움직이기 · 채집 · 도구 · 건설 · 텃밭 · 정령 · 세계수 설명과 "활동력이 없어요 / 가방이 꽉 찼어요" 같은 상황별 해결법도 들어 있고, 40초 동안 아무 진척이 없으면 스스로 힌트를 한 번 띄웁니다.

## ⚔️ Math Quest — `games/fun/math-quest/`

**"수학 문제집"이 아니라 "모험을 계속하려고 문제를 푸는" 성장형 RPG**입니다. (8~13살)

- **정답 = 공격, 오답 = 피격.** 콤보를 쌓으면 경험치가 ×2 → ×3 → ×5 → ×10 으로 커지고 **5콤보마다 필살기**가 터집니다.
- **문제 유형 56종** — 덧셈·뺄셈·곱셈·나눗셈·혼합계산·분수·소수·약수배수·단위환산·문장제부터 도형·각도·넓이·전개도·쌓기나무·좌표, 수열·규칙찾기·행렬추리·참말거짓말·암호·저울·미로·최단경로·성냥개비·IQ, 시계·달력·확률·경우의 수·평균·비율·빠르기·그래프까지 무작위로 나옵니다.
- **학년 표현이 전혀 없습니다.** 난이도는 Lv 1~100 과 Easy → Normal → Hard → Expert → Master → Grand Master → Legend → Mythic 등급으로만 말합니다.
- **적응형 난이도** — 시작할 때 실력 시험 5문제로 출발점을 잡고, 그 뒤로는 **최근 20문제의 정답률과 걸린 시간**을 보고 자동으로 오르내립니다(95% 이상이면 +3, 55% 아래면 -1~-3). 항상 "조금 어렵지만 풀 수 있는" 상태를 유지합니다.
- **지역 8곳** — 초원의 마을 → 슬라임 숲 → 얼음 동굴 → 피라미드 → 마법도서관 → 기계도시 → 용의 산 → 우주. 레벨이 되면 열리고, 각 지역 끝에는 12~50문제 연속 도전인 **보스**가 있습니다. 몬스터 56종.
- **수집** — 무기·갑옷·모자·펫·날개·탈것·스킨 7칸에 장비 59종(흔함/희귀/영웅/전설/신화). 몬스터를 잡으면 상자가 떨어지고, 도감(몬스터·아이템·문제 유형)과 **업적 132개**를 채웁니다.
- **랜덤 던전 10종** — 거울의 방·질주의 통로·황금 금고·어둠의 회랑·시련의 심연 등, 들어갈 때마다 규칙과 보상이 달라집니다.
- **일일 미션 4개 · 주간 미션 3개 · 4주 단위 시즌 패스**로 매일 돌아올 이유를 만듭니다.
- **전투 도우미** — 힌트 · 50:50 · 시간 +10초 · 정답 보호막 · 부활 · 체력 물약을 골드로 사서 씁니다. 레벨업으로 받는 **스킬포인트**는 공격·방어·체력·문제 시간·행운에 영구 투자합니다.
- **분야별 능력치 5종**(연산·도형·논리·추리·확률)이 따로 레벨업해서 아이마다 캐릭터 개성이 생깁니다.
- **보호자 보기(숨김)** — 오른쪽 위 ⚙️ → 보호자 보기. 아이 화면에는 없는 메뉴로, 분야별 정답률·평균 풀이 시간·더 연습하면 좋은 유형·최근 7일 기록을 볼 수 있습니다.
- 결제·광고·채팅·로그인이 없고, 효과음은 Web Audio 합성입니다. 진행은 자동 저장됩니다.
- 플레이어별 최고 레벨과 배지 8종이 남습니다. **온라인 순위표는 쓰지 않습니다**(내 캐릭터를 키우는 게임이라서요).
