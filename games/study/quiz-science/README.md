# 🧠 상식·과학 퀴즈

O/X와 4지선다가 섞인 상식 퀴즈입니다. **문제마다 왜 그런지 해설**이 나옵니다.
**6살부터 초등 6학년까지** 나이에 맞는 4단계(총 **190문제**)를 고를 수 있고,
친구와 **방 코드 온라인 대결**도 할 수 있어요.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/study/quiz-science/**

## 모드

| 모드 | 설명 |
|---|---|
| 혼자 풀기 | 고른 단계·주제·문제 수만큼 풀고, 점수·정확도·최고 연속을 확인합니다. |
| 틀린 문제만 다시 | 결과 화면에서 오답만 모아 다시 풀 수 있습니다. |
| 🌐 친구랑 온라인 대결 | 방 코드로 만나 **똑같은 문제 세트**를 각자 풀고 점수로 승부합니다. |

## 나이 4단계 (문제 190개)

| 단계 | 문제 수 | 어떤 문제? |
|---|---|---|
| 🐣 6~7살 | 45문제 | "맑은 낮 하늘은 무슨 색?" 처럼 그림 없이도 아는 상식 |
| 🐤 초1~2 | 43문제 | 자석·그림자·포유류·명절처럼 학교에서 막 배우기 시작한 내용 |
| 🐥 초3~4 | 58문제 | 광합성·태양계·삼국시대 등 교과서 기본 |
| 🦅 초5~6 | 44문제 | 굴절·산화·삼권분립·3·1 운동 등 교과 심화 |

주제는 **과학 · 우주 · 동물·자연 · 한국·사회 · 역사 · 생활상식** 6가지이며,
네 단계 모두 같은 6주제를 갖고 있어 여러 개를 함께 고를 수 있습니다.
문제 수는 10 / 20 / 전부 중에서 선택합니다.

## 규칙 / 난이도

- 보기는 **4지선다** 또는 **O/X** 두 가지입니다. O/X는 자동으로 크게 두 칸으로 표시됩니다.
- 4지선다는 매번 **보기 순서가 섞여** 나옵니다.
- 정답 하나에 **10점**, 연속으로 맞히면 **연속 보너스**(2점씩, 최대 +10점)가 붙습니다.
- 맞히든 틀리든 **해설 카드가 열립니다.** 틀린 문제를 그냥 넘어가지 않는 것이 이 게임의 핵심입니다.
  모든 문제에 해설이 붙어 있습니다.
- 정확도에 따라 메달을 받습니다. (🥉 → 🥈 → 🥇 → 🏆)
- 온라인 대결에서는 방장이 고른 **나이 단계 · 주제 · 문제 수**가 양쪽에 그대로 적용됩니다.

## 조작법

- 모두 **터치 / 클릭**만으로 조작합니다.
- 보기를 누르면 채점 → 해설 → `다음 문제 →` 버튼으로 진행합니다.
- 온라인 대결: `🌐 친구랑 온라인 대결` → 이름 입력 → **방 만들기**(방장) 또는 **방 참여하기**(4글자 코드 입력).

## 문제 추가하기

`index.html` 위쪽 `BANKS` 안, 원하는 단계(`lv1`~`lv4`)의 주제에 한 덩어리 넣으면 바로 반영됩니다.

```js
{q:"물이 얼면 부피는 어떻게 될까요?",
 a:["늘어난다","줄어든다","그대로다","반으로 준다"],
 c:0,                                    // 정답 번호 (0부터 셈)
 e:"물은 얼면서 <b>부피가 늘어나요</b>."}   // 해설
```

- 보기를 `["O","X"]` 로 하면 자동으로 **O/X 문제**가 됩니다. (`c:0` 이면 정답 O, `c:1` 이면 정답 X)
- 해설의 `<b>...</b>` 는 굵게 표시됩니다.
- 정답이 여러 개일 수 있는 애매한 문제, 사실이 확실하지 않은 문제는 넣지 않습니다.

## 기술 메모

- 순수 HTML/CSS/JS 단일 파일. 빌드 도구·npm 없음. 모바일 우선 반응형.
- 문제 은행은 `BANKS = { lv1, lv2, lv3, lv4 }` 구조이며, 각 문제는 `{ q, a, c, e }`
  (질문 / 보기 배열 / 정답 인덱스 / 해설)입니다.
- 게임 데이터에 `localStorage`를 쓰지 않습니다. 모든 상태는 메모리 변수(`S`)에 둡니다.
- 온라인 대결은 공용 라이브러리 `common/versus.js`(P2P/WebRTC)를 사용합니다.
  - 문제 뽑기와 보기 순서 섞기를 모두 `Versus.seeded()` 안에서 처리해 **양쪽이 완전히 같은 세트**를 받습니다.
  - `seeded()` 안에서는 이름·화면 크기·오답노트처럼 **사람마다 다른 값을 쓰지 않습니다.** (난수가 어긋나는 것을 막기 위함)
  - 점수가 바뀌면 `Versus.setScore()`, 다 풀면 `Versus.finish()`.
- 온라인 전용 코드는 파일 아래쪽 `/* ══ 온라인 대결 ══ */` 블록 한 곳에 모여 있습니다.
- 검증 스크립트: 저장소 루트의 `test_quiz.js` (데이터 무결성 · 단계별 플레이 · 2인 온라인 동기화).
