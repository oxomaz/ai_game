# 🧠 상식·과학 퀴즈

O/X와 4지선다가 섞인 상식 퀴즈입니다. **문제마다 왜 그런지 해설**이 나옵니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/study/quiz-science/**

## 특징

- **주제 6가지 · 총 43문제**
  과학(10) · 우주(7) · 동물과 자연(7) · 한국과 사회(7) · 역사(5) · 생활상식(7)
- 맞히든 틀리든 **해설 카드가 열립니다.** 틀린 문제를 그냥 넘어가지 않는 것이 이 게임의 핵심입니다.
- O/X 문제는 자동으로 크게 두 칸으로 표시되고, 4지선다는 매번 **보기 순서가 섞입니다.**
- 연속 정답 보너스, 정확도에 따른 메달 (🥉 → 🥈 → 🥇 → 🏆)
- 끝나면 **틀린 문제만 다시** 풀 수 있고, 해설을 모아 복습할 수 있습니다.

## 문제 추가하기

`index.html` 맨 위 `BANK` 목록에 한 줄 넣으면 바로 반영됩니다.

```js
{q:"물이 얼면 부피는 어떻게 될까요?",
 a:["늘어난다","줄어든다","그대로다","반으로 준다"],
 c:0,                                    // 정답 번호 (0부터 셈)
 e:"물은 얼면서 <b>부피가 늘어나요</b>."}   // 해설
```

- 보기를 `["O","X"]` 로 하면 자동으로 **O/X 문제**가 됩니다. (`c:0` 이면 정답 O, `c:1` 이면 정답 X)
- 해설의 `<b>...</b>` 는 굵게 표시됩니다.
- 새 주제는 `"주제이름": [ ... ]` 를 통째로 추가하면 됩니다.
