## 학습용 게임에만 적용되는 규칙

1. **대상은 초등학교 저·중학년(8~11세)이다.** 문장은 짧고 쉬운 한국어로 쓰고, 한자어·영어 UI 용어를 피한다.
2. **문제·정답 데이터는 파일 맨 위 상수(`WORDS`, `BANK` 등)에 모아두고**, 주석으로 "여기에 추가하면 바로 반영됩니다"라고 표시한다. 부모가 문제를 직접 늘릴 수 있어야 한다.
3. **틀렸을 때 그냥 넘어가지 않는다.** 정답과 함께 **왜 그런지 짧은 해설**을 보여주고, 게임이 끝나면 **틀린 문제만 다시** 풀 수 있게 한다.
4. **문제는 자동 검증한다.** 자동 생성 문제(연산 등)는 규칙을 그대로 시뮬레이션해 ① 정답이 유일한지 ② 음수·소수처럼 학년 범위를 벗어난 답이 나오지 않는지 ③ 오답 보기가 정답과 겹치지 않는지 확인한 뒤 커밋한다.
5. **지식 문제(퀴즈·단어)는 사실 확인을 거친다.** 애매하거나 논쟁적인 문제는 넣지 않는다.
6. **아이가 실패해도 기분 나쁘지 않게 만든다.** 오답에 큰 페널티를 주지 말고, 연속 정답 보너스·칭찬 메시지처럼 긍정적 보상을 우선한다.
