# ⚡ 연산 스피드 퀴즈

제한 시간 안에 사칙연산 문제를 **최대한 많이** 푸는 게임입니다.
6살부터 초등 6학년까지, **나이에 맞는 4단계**로 문제가 나옵니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/study/math-speed/**

## 모드

| 모드 | 설명 |
|---|---|
| 혼자 하기 | 제한 시간 안에 최대한 많이 맞히기. 최고 기록이 저장됩니다. |
| 🌐 친구랑 온라인 대결 | 방 코드를 주고받아 둘이 **똑같은 문제 세트**를 각자 풀고 점수를 겨룹니다. |

## 나이 단계 (난이도)

시작 화면에서 나이를 고르면 문제 범위 · 제한 시간 · 오답 벌칙이 함께 바뀝니다.

| 단계 | 나오는 문제 | 기본 시간 | 오답 벌칙 |
|---|---|---|---|
| 🐣 6~7살 | 10 이하 덧셈·뺄셈 (받아올림·받아내림 **없음**) | 120초 | 없음 |
| 🐤 초1~2 | 두 자리 덧셈·뺄셈 (받아올림·받아내림 포함) | 90초 | −2초 |
| 🐥 초3~4 | 구구단·두 자리 곱셈, 세 자리 덧셈·뺄셈, **나머지 있는 나눗셈**(몫/나머지 구하기) | 60초 | −3초 |
| 🦅 초5~6 | **분수·소수 사칙연산**, 네 자리 덧셈·뺄셈, 두 자리 곱셈, **괄호 혼합계산** | 60초 | −3초 |

- 나이를 고르면 그 단계에서 배울 **연산 종류만** 나타납니다. (6~7살은 덧셈·뺄셈만, 초5~6은 🧮 혼합·괄호까지)
- 답이 **음수가 되는 문제는 나오지 않습니다.** 나머지는 항상 `0 < 나머지 < 나누는 수`.
- 분수 답은 항상 **기약분수**, 소수 답은 **소수 첫째 자리**까지입니다.

## 규칙

- 정답 = **10점 + 연속 보너스(최대 +20) + 나이 단계 보너스**
- 3연속 이상 맞히면 🔥 연속 표시가 뜹니다.
- 끝나면 **틀린 문제를 정답과 함께** 모아 보여줍니다.
- 최고 기록은 (나이 단계 · 연산 조합 · 시간)별로 따로 저장됩니다.

## 조작

- 모바일 — 화면 숫자 키패드 터치
- PC — 숫자키 입력, `Enter` 확인, `Backspace` 지우기
- **초5~6 단계에서만** `· 소수점` / `／ 분수` 키가 추가로 나옵니다. (예: `0.8`, `5/6`)
- **자동 채점** — 정수 답은 자릿수만큼 입력하면 확인 버튼 없이 바로 넘어갑니다.
  소수·분수 답은 다 쓴 뒤 `확인`(Enter)을 눌러 주세요.

## 온라인 대결

1. 한 명이 시작 화면에서 **나이 단계·연산**을 고르고 `🌐 친구랑 온라인 대결 → 방 만들기`
2. 나온 **4글자 방 코드**를 친구에게 알려줍니다.
3. 친구는 같은 게임에서 `방 참여하기`에 코드를 입력합니다.
4. 방장이 **문제 수(5·10·20)** 를 고르고 `대결 시작!` — 둘 다 똑같은 문제를 순서대로 풉니다.
5. 상단 VS 바에 서로의 점수가 실시간으로 보이고, 둘 다 끝나면 승패 화면이 뜹니다.

## 기술 메모

- 순수 HTML/CSS/JS 단일 파일. 빌드 도구 없음.
- 온라인 대결은 공용 라이브러리 `common/versus.js`(PeerJS P2P)를 씁니다.
  문제 생성은 전부 `Versus.seeded()` 안에서 실행해 **양쪽이 같은 시드로 완전히 동일한 문제 세트**를 만듭니다.
  화면 크기·이름처럼 사람마다 다른 값은 시드 블록 안에서 쓰지 않습니다.
- 소수 계산은 **10배 정수**로 처리해 부동소수점 오차를 없앴습니다. 분수는 `gcd`로 기약분수까지 약분합니다.
- `localStorage`는 `try/catch`로 감싸고, 막혀 있으면 메모리 저장으로 자동 대체됩니다.
- 검증 스크립트 `test_math.js` — 4단계 각 **1000문제**를 생성해 문제 글자를 독립 파서로 다시 계산,
  정답·범위(음수 금지·나머지 범위·기약분수)를 확인하고 실제 플레이와 2인 온라인 대결까지 자동 테스트합니다.
