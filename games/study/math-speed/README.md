# ⚡ 연산 스피드 퀴즈

제한 시간 안에 사칙연산 문제를 **최대한 많이** 푸는 게임입니다.

**▶ 플레이: https://oxomaz.github.io/ai_game/games/study/math-speed/**

## 특징

- **연산 고르기** — 덧셈 · 뺄셈 · 곱셈 · 나눗셈을 원하는 대로 조합 (여러 개 동시 선택 가능)
- **난이도 3단계**

  | | 덧셈 | 뺄셈 | 곱셈 | 나눗셈 |
  |---|---|---|---|---|
  | 쉬움 | 10 이내 + 10 이내 | 18 이내 | 2~5단 | 몫 한 자리 |
  | 보통 | 두 자리 + 두 자리 | 두 자리 | 구구단 전체 | 몫 한 자리 |
  | 어려움 | 세 자리 + 세 자리 | 세 자리 | (두 자리)×(한 자리) | 몫 두 자리 |

- **나눗셈은 항상 딱 나누어떨어지게** 출제됩니다. 소수·나머지가 나오지 않습니다.
- 뺄셈 결과가 **음수가 되지 않도록** 문제를 만듭니다.
- 시간 30 / 60 / 120초 선택. 오답이면 **−3초**, 연속 정답이면 최대 **+20점 보너스**
- **자동 채점** — 정답 자릿수만큼 입력하면 확인 버튼을 누르지 않아도 바로 다음 문제로 넘어갑니다.
- 끝나면 **틀린 문제를 정답과 함께** 모아 보여줍니다.
- 최고 기록은 (연산 조합 · 난이도 · 시간)별로 따로 저장됩니다.

## 조작

- 모바일 — 화면 숫자 키패드 터치
- PC — 숫자키 입력, `Enter` 확인, `Backspace` 지우기
