# 🚀 구구단 슈팅

화면 위에서 내려오는 숫자 풍선 중 **정답을 골라 쏘는** 액션 게임입니다.

**▶ 플레이: https://oxomaz.github.io/ai_game/games/study/times-table-shooter/**

## 특징

- **연습할 단을 직접 고릅니다** — 2단부터 9단까지, 여러 개 동시 선택 가능. 틀리는 단만 골라서 집중 연습할 수 있습니다.
- **오답 보기가 진짜 헷갈립니다** — `7 × 8`의 오답으로 `7 × 7`, `8 × 8` 처럼 **한 칸 옆 구구단 값**을 주로 뽑습니다. 대충 찍어서는 맞히기 어렵습니다.
- 목숨 3개. 오답을 쏘거나 정답 풍선을 놓치면 하나 줄어듭니다.
- **5개 맞힐 때마다 단계 상승** — 풍선이 조금씩 빨라집니다.
- 속도 3단계 (느리게 · 보통 · 빠르게)
- 게임이 끝나면 **자주 틀린 구구단**을 횟수와 함께 모아서 보여줍니다.
- 최고 기록은 (선택한 단 조합 · 속도)별로 따로 저장됩니다.

## 조작

- 풍선 터치 / 클릭 — 아래 우주선이 그쪽으로 레이저를 쏩니다.
