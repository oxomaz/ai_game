# 🚀 구구단 슈팅

화면 위에서 내려오는 숫자 풍선 중 **정답을 골라 쏘는** 액션 게임입니다.
6살부터 초등 6학년까지, **나이에 맞는 4단계**로 문제와 속도가 바뀝니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/study/times-table-shooter/**

## 모드

| 모드 | 설명 |
|---|---|
| 혼자 하기 | 목숨이 다할 때까지. 5개 맞힐 때마다 단계가 올라 조금씩 빨라집니다. |
| 🌐 친구랑 온라인 대결 | 방 코드를 주고받아 둘이 **똑같은 문제·똑같은 보기**를 각자 풀고 점수를 겨룹니다. |

## 나이 단계 (난이도)

| 단계 | 나오는 문제 | 보기 | 낙하 속도 | 목숨 |
|---|---|---|---|---|
| 🐣 6~7살 | 2단 · 5단만 | 2개 (아주 큼) | 아주 느리게 (약 23px/초) | 5개 |
| 🐤 초1~2 | 2~5단 | 3개 | 느리게 (약 39px/초) | 4개 |
| 🐥 초3~4 | 구구단 전체 (2~9단) | 4개 | 보통 (약 82px/초) | 3개 |
| 🦅 초5~6 | 구구단 + **나눗셈(몫 맞히기)** + **두 자리 × 한 자리** | 4개 | 빠르게 (약 118px/초) | 3개 |

- **연습할 단 고르기는 그대로 유지됩니다.** 나이를 고르면 그 나이에 맞는 단이 자동으로 켜지고,
  그 안에서 원하는 단만 다시 골라 집중 연습할 수 있습니다. (6~7살은 2·5단만 나타납니다.)
- 속도 3단계(느리게 · 보통 · 빠르게)는 나이 단계 위에 얹히는 **미세 조절**입니다. 어린 단계는 `느리게`가 기본값입니다.

## 규칙

- **오답 보기가 진짜 헷갈립니다** — `7 × 8`의 오답으로 `7 × 7`, `8 × 8` 처럼 **한 칸 옆 구구단 값**을 주로 뽑습니다.
- 오답을 쏘거나 정답 풍선을 놓치면 목숨이 하나 줄어듭니다.
- 정답 = **10점 + 단계 보너스 + 나이 단계 보너스**
- 게임이 끝나면 **자주 틀린 문제**를 횟수와 함께 모아서 보여줍니다.
- 최고 기록은 (나이 단계 · 선택한 단 조합 · 속도)별로 따로 저장됩니다.

## 조작

- 풍선 터치 / 클릭 — 아래 우주선이 그쪽으로 레이저를 쏩니다.

## 온라인 대결

1. 한 명이 시작 화면에서 **나이 단계·단·속도**를 고르고 `🌐 친구랑 온라인 대결 → 방 만들기`
2. 나온 **4글자 방 코드**를 친구에게 알려줍니다.
3. 친구는 같은 게임에서 `방 참여하기`에 코드를 입력합니다.
4. 방장이 **문제 수(5·10·20)** 를 고르고 `대결 시작!`
5. 둘 다 똑같은 문제·보기를 순서대로 받고, 상단 VS 바에 서로의 점수가 실시간으로 보입니다.
   문제를 다 풀거나 목숨이 떨어지면 끝나고, 둘 다 끝나면 승패 화면이 뜹니다.

## 기술 메모

- 순수 HTML/CSS/JS 단일 파일. 빌드 도구 없음.
- 온라인 대결은 공용 라이브러리 `common/versus.js`(PeerJS P2P)를 씁니다.
  문제 · 보기 값 · 풍선이 내려오기 시작하는 위치까지 **전부 `Versus.seeded()` 안에서 미리 생성**해
  양쪽이 100% 동일한 세트를 받습니다. 화면 폭 같은 기기별 값은 시드 블록 밖에서 처리합니다.
- `localStorage`는 `try/catch`로 감싸고, 막혀 있으면 메모리 저장으로 자동 대체됩니다.
- 검증 스크립트 `test_times.js` — 4단계 각 **1000문제**를 생성해 문제 글자를 독립 채점기로 다시 계산,
  정답·보기(정답 1개·중복 없음·모두 양수)·단 범위를 확인하고 실제 플레이와 2인 온라인 대결까지 자동 테스트합니다.
