# 🔤 영단어 카드 퀴즈

플래시카드로 영단어를 외우고 바로 4지선다 퀴즈로 확인하는 학습 게임입니다.
**6살부터 초등 6학년까지** 나이에 맞는 4단계 단어장(총 **484개**)을 고를 수 있고,
친구와 **방 코드 온라인 대결**도 할 수 있어요.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/study/word-cards/**

## 모드

| 모드 | 설명 |
|---|---|
| 📇 카드 외우기 | 카드를 눌러 뒤집으며 단어 ↔ 뜻을 외웁니다. 이전/다음으로 자유롭게 이동. |
| 영어 → 뜻 | 영어 단어를 보고 알맞은 한국어 뜻을 고릅니다. |
| 뜻 → 영어 | 한국어 뜻을 보고 알맞은 영어 단어를 고릅니다. |
| 🌐 친구랑 온라인 대결 | 방 코드로 만나 **똑같은 단어 세트**를 각자 풀고 맞힌 개수로 승부합니다. |

## 나이 4단계 (단어 484개)

| 단계 | 단어 수 | 주제 | 어떤 낱말? |
|---|---|---|---|
| 🐣 6~7살 | 111개 | 동물 · 색깔 · 숫자 · 먹는 것 · 탈것/물건 · 몸/가족 · 자연 | `cat` `red` `three` 처럼 그림으로 바로 떠오르는 낱말 |
| 🐤 초1~2 | 106개 | 학교 · 가족/사람 · 음식 · 집/물건 · 날씨/계절 · 동작 · 느낌/모양 | `teacher` `breakfast` `winter` 같은 생활 기초 낱말 |
| 🐥 초3~4 | 160개 | 동물 · 음식 · 학교 · 몸/감정 · 색/숫자 · 집/물건 · 자연/날씨 · 동작 | 교과서에 자주 나오는 기본 단어 |
| 🦅 초5~6 | 107개 | 학교/교과 · 자연/과학 · 사람/성격 · 동사 · 형용사 · 사회/생활 · 시간/수 | `environment` `important` `discover` 같은 2음절 이상 교과 어휘 |

주제는 여러 개를 함께 고를 수 있고, 문제 수는 10 / 20 / 전부 중에서 선택합니다.

## 규칙 / 난이도

- 퀴즈 보기는 4개이며, 오답 보기를 **같은 주제 안에서 먼저** 뽑습니다.
  (예: `frog`의 오답 보기가 '돼지 · 원숭이 · 사자') 주제가 달라서 찍어 맞히는 일이 없습니다.
- 단계가 올라갈수록 낱말이 길어지고 뜻이 추상적이 됩니다.
- 결과 화면에서 정확도(점수)와 틀린 단어 목록을 보여주고, **틀린 단어만 다시** 풀 수 있습니다.
- 온라인 대결에서는 방장이 고른 **나이 단계 · 주제 · 문제 수 · 퀴즈 방식**이 양쪽에 그대로 적용됩니다.
  (방장이 '카드 외우기'를 골라둔 경우 대결은 '영어 → 뜻' 퀴즈로 진행됩니다.)

## 조작법

- 모두 **터치 / 클릭**만으로 조작합니다.
- 카드 모드: 카드를 누르면 뒤집히고, `← 이전` / `다음 →` 로 넘깁니다.
- 🔊 **발음 듣기** 버튼으로 영어 발음을 들을 수 있습니다.
- 온라인 대결: `🌐 친구랑 온라인 대결` → 이름 입력 → **방 만들기**(방장) 또는 **방 참여하기**(4글자 코드 입력).

## 단어 추가하기

`index.html` 위쪽 `LEVELS` 안, 원하는 단계의 주제에 `["단어","뜻"]` 한 줄만 넣으면 바로 반영됩니다.

```js
{ key:"lv3", label:"🐥 초3~4", ...
  words:{
    "동물":[
      ["dog","개"],
      ["turtle","거북"]      // ← 이렇게 한 줄 추가
    ]
  }
}
```

새 주제는 `"주제이름": [ ... ]` 를 통째로 추가하면 됩니다.
단, **한 주제에 최소 4개**는 있어야 4지선다가 만들어집니다.

## 기술 메모

- 순수 HTML/CSS/JS 단일 파일. 빌드 도구·npm 없음. 모바일 우선 반응형.
- 발음은 브라우저 내장 `speechSynthesis`(`en-US`). 지원하지 않는 기기에서는 버튼을 눌러도 아무 일이 없을 뿐, 게임은 그대로 진행됩니다.
- 게임 데이터에 `localStorage`를 쓰지 않습니다. 모든 상태는 메모리 변수(`S`)에 둡니다.
- 온라인 대결은 공용 라이브러리 `common/versus.js`(P2P/WebRTC)를 사용합니다.
  - 단어 뽑기와 보기 4개 만들기를 모두 `Versus.seeded()` 안에서 처리해 **양쪽이 완전히 같은 세트**를 받습니다.
  - `seeded()` 안에서는 이름·화면 크기·오답노트처럼 **사람마다 다른 값을 쓰지 않습니다.** (난수가 어긋나는 것을 막기 위함)
  - 점수가 바뀌면 `Versus.setScore()`, 다 풀면 `Versus.finish()`.
- 온라인 전용 코드는 파일 아래쪽 `/* ══ 온라인 대결 ══ */` 블록 한 곳에 모여 있습니다.
- 검증 스크립트: 저장소 루트의 `test_words.js` (데이터 무결성 · 단계별 플레이 · 2인 온라인 동기화).
