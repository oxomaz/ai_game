# 🔤 영단어 카드 퀴즈

초등 3학년 수준 영단어 **120개**를 외우고 확인하는 게임입니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/study/word-cards/**

## 특징

- **주제 8가지 × 각 15개 = 120개**
  동물 · 음식 · 학교 · 몸과 감정 · 색과 숫자 · 집과 물건 · 자연과 날씨 · 동작
- **방식 3가지**
  - 📇 **카드 외우기** — 카드를 눌러 뒤집으며 단어와 뜻을 익힙니다. 이전/다음으로 자유롭게 이동.
  - **영어 → 뜻** 4지선다
  - **뜻 → 영어** 4지선다
- 오답 보기를 **같은 주제 안에서** 뽑습니다. (예: `frog`의 오답 보기가 '돼지 · 원숭이 · 사자') 주제가 달라서 찍어 맞히는 일이 없습니다.
- 🔊 **발음 듣기** — 브라우저 음성 합성 기능을 사용합니다. 지원하지 않는 기기에서는 버튼을 눌러도 아무 일이 없을 뿐, 게임은 그대로 진행됩니다.
- 끝나면 **틀린 단어만 골라 다시** 풀 수 있습니다.

## 단어 추가하기

`index.html` 맨 위 `WORDS` 목록에 `["단어","뜻"]` 한 줄만 넣으면 바로 반영됩니다.

```js
var WORDS = {
  "동물": [
    ["dog","개"],
    ["cat","고양이"],
    ["turtle","거북"]      // ← 이렇게 한 줄 추가
  ],
  ...
};
```

새 주제를 만들고 싶으면 `"주제이름": [ ... ]` 를 통째로 추가하면 됩니다.
단, **한 주제에 최소 4개**는 있어야 4지선다가 만들어집니다.
