# 🏃 점프맵 100

발판을 밟고 뛰어올라 목표 지점까지 도달하는 **100단계 파쿠르 점프맵**입니다.
레벨이 올라갈수록 발판이 좁아지고 간격이 멀어지며, 새로운 장애물이 하나씩 추가됩니다.

**▶ 플레이: https://oxomaz.github.io/ai_game/games/jump-map/**

## 특징

- **레벨 1 ~ 100** — 단계가 올라갈수록 난이도가 완만하게 상승합니다
- **닉네임 프로필** — 한 컴퓨터에서 여러 명이 각자 닉네임을 만들어 따로 플레이합니다
- **캐릭터 12종** — 네모 · 고양이 · 개구리 · 로봇 · 유령 · 펭귄 · 병아리 · 공룡 · 닌자 · 마법사 · 슬라임 · 별똥별
- **기록실** — 클리어 수 · 별 · 총 기록 · 최고 도달 레벨로 플레이어끼리 순위를 겨룹니다
- **별 3개 수집** — 레벨마다 숨은 별 3개. 안 먹어도 클리어는 되지만 기록에 남습니다
- **체크포인트** — 긴 레벨에는 중간 깃발이 있어 죽어도 그 지점부터 다시 시작합니다
- **최고기록** — 레벨별 기록이 저장되고, 기록을 깨면 `✦ 신기록! ✦` 표시

## 발판 종류

| 발판 | 등장 | 특징 |
|---|---|---|
| 일반 | 1레벨 | 그냥 밟는 발판 |
| 🟪 이동 발판 | 7레벨 | 좌우(⇄) 또는 위아래(⇅)로 왕복. 타이밍 맞춰 올라타기 |
| 🟧 컨베이어(무빙워크) | 12레벨 | 서 있기만 해도 앞뒤로 밀려남. 뒤로 미는 발판은 달려야 제자리 |
| 🟫 부서지는 발판 | 16레벨 | 밟고 잠시 뒤 무너짐. 조금 있다 복구 |
| 🟩 트램폴린 | 22레벨 | 밟으면 1.5배 높이로 강제 발사 |
| 🟪 점멸 발판 | 26레벨 | 나타났다 사라졌다 반복. 발판 아래 게이지가 남은 시간 |
| 🧊 얼음 발판 | 40레벨 | 마찰 거의 없음. 미끄러져서 멈추기 어려움 |

## 장애물

| 장애물 | 등장 | 특징 |
|---|---|---|
| 🔺 가시 | 5레벨 | 발판 위 고정. 뛰어넘어야 함 |
| 🔻 튀어나오는 가시 | 20레벨 | 주기적으로 솟았다 들어감. 빨간 줄이 깜빡이면 곧 올라온다는 신호 |
| ⚙️ 톱날 | 14레벨 | 틈새를 위아래로 순찰하거나 넓은 발판 위를 좌우로 왕복 |
| 🔴 레이저 | 30레벨 | 껐다 켜졌다 반복. 꺼진 틈에 통과 |
| ✳️ 회전 가시봉 | 34레벨 | 기둥을 중심으로 가시 달린 팔이 빙빙 돎. 팔이 지나간 직후에 통과 |
| 💥 대포 | 48레벨 | 일정 간격으로 탄을 발사. 포구가 빨개지면 곧 발사 |
| 🧱 추격 가시벽 | 90레벨 | 뒤에서 가시벽이 천천히 쫓아옴. 죽거나 체크포인트를 찍으면 뒤로 물러남 |

## 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 좌 · 우 이동 | `←` `→` 또는 `A` `D` | 화면 아래 ◀ ▶ 버튼 |
| 점프 | `Space` / `↑` / `W` | ▲ 버튼 |
| 재시작 | `R` | ↺ 버튼 |
| 레벨 목록 | `ESC` | ☰ 버튼 |

점프 키를 짧게 누르면 낮게, 길게 누르면 높게 뜁니다. 발판 끝에서 살짝 늦게 눌러도 점프가 됩니다(코요테 타임).
모바일은 **가로 화면**을 권장합니다.

## 기술 메모

- 단일 HTML 파일, Canvas 기반 물리·렌더링. 캐릭터도 이미지 없이 전부 코드로 그립니다
- 레벨은 시드 기반으로 자동 생성되며, 같은 레벨은 항상 같은 맵입니다
- 발판 간격은 **점프 도달거리 공식(`reachDx`)의 90% 이내**로 제한되고, 이동 발판은 가장 불리한 위치를 기준으로 계산합니다
- 100개 레벨의 모든 점프 구간과 별 3개를 실제 물리 그대로 시뮬레이션해 **클리어·수집 가능 여부를 검증**한 뒤 포함되었습니다
- 진행상황·기록은 `localStorage`에 저장하되, 접근이 막히면 메모리 저장으로 자동 대체되어 게임이 멈추지 않습니다
