# 🔤 끝말잇기 (word-chain)

앞사람이 말한 단어의 **마지막 글자로 시작하는 단어**를 이어 말하는 고전 단어 게임입니다.
컴퓨터와 1:1로 겨루거나, 한 화면에서 최대 8명이 돌아가며 즐기거나, 멀리 있는 친구와 온라인으로 대결할 수 있습니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/fun/word-chain/**

## 모드

### 🤖 컴퓨터와 대결

- **쉬움 / 보통 / 어려움** 3단계
- 난이도가 올라갈수록 컴퓨터가 이어가기 어려운 글자를 남기도록 단어를 고릅니다
- 먼저 시작하는 쪽을 **나 / 컴퓨터 / 랜덤** 중에서 선택

### 👥 여러 명이서 함께

- 최대 **8명**까지 이름을 입력하고 한 화면에서 순서대로 진행
- **순서 랜덤 섞기** 지원 — 시작 전에 차례를 섞을 수 있습니다
- 자기 차례에 단어를 못 내면 탈락, 마지막까지 남은 사람이 승리

### 🌐 친구랑 온라인 대결

시작 화면의 **🌐 친구랑 온라인 대결** 버튼으로 방을 만들거나, 친구가 알려준 **4글자 방 코드**를 넣어 입장합니다.
두 사람은 같은 시드로 **똑같은 제시어**를 받고, 방장이 선공으로 번갈아 단어를 잇습니다. 내 차례에만 입력창이 열리고, 시간을 넘기거나 포기하면 집니다.
서버는 없습니다 — 브라우저끼리 직접 연결(WebRTC/P2P)하고, 연결 중개만 PeerJS를 씁니다. 공용 코드는 `common/versus.js`.

## 규칙 옵션

- **제한 시간** — 한 턴에 15초씩, 또는 시간 제한이 없는 **자유 모드**
- **자유 모드(사전 밖 단어 허용)** — 켜면 사전에 없는 단어도 통과시켜, 아이들과 느슨하게 즐길 때 좋습니다
- 이미 나온 단어는 다시 쓸 수 없고, 두 글자 이상만 쓸 수 있습니다
- **두음법칙**을 적용합니다. 예: '력'으로 끝나면 '력' 또는 '역'으로 시작해도 인정

## 📚 낱말 31만 개 인정 사전

"국어사전에 있는 말인데 왜 안 되냐"는 답답함을 없애려고, 국어사전 낱말 목록을 게임용으로 거른 **31만 개**짜리 인정 사전(`words-ko.js`)을 함께 씁니다.

- 플레이어가 낸 단어는 **31만 낱말 사전 · 게임 기본 낱말 목록 · 요즘말 보충 목록** 중 **어디 하나에라도 있으면 통과**합니다. 사전은 넓히기만 하고 좁히지 않습니다.
- 사전 파일은 1.6MB라 **비동기로** 불러옵니다. 준비되기 전에도 게임을 시작할 수 있고, 그동안에는 기본 낱말 목록으로 판정하다가 준비되면 조용히 확장 사전으로 넘어갑니다. 시작 화면에 `낱말 사전 준비 중… → 낱말 31만 개 준비 완료 ✅` 표시가 뜹니다.
- 파일을 못 불러와도(오프라인 등) 게임은 기본 낱말 목록만으로 그대로 돌아갑니다.
- **제시어와 컴퓨터(AI)가 내는 단어는 언제나 쉬운 기본 낱말 목록에서만** 고릅니다. 확장 사전에는 아이가 모를 어려운 말이 많아 AI가 쓰면 재미가 없기 때문입니다.

## 💡 포기하면 정답을 알려줘요

포기하거나 시간이 지나면, 그 차례에 **낼 수 있었던 단어를 최대 5개** 보여줍니다.

- 아이가 알 만한 말이 먼저 보이도록 **쉬운 기본 낱말을 먼저** 고르고, 모자라면 확장 사전에서 채웁니다.
- 이을 말이 정말 하나도 없으면 `이 단어는 이을 말이 없는 '한방 단어'였어요! 진 게 아니에요 😆` 라고 알려줍니다.
- 컴퓨터 대결 · 로컬 멀티 · 온라인 대결 **모든 모드**에서 동작합니다. 여러 명이 할 때는 게임이 계속되므로 게임 화면에 쪽지로 뜨고, 게임이 끝나면 결과 화면에 뜹니다.

## 조작

키보드로 단어를 입력하고 `Enter`. 모바일에서는 화면 입력창을 사용합니다.

## 기술 메모

- 순수 HTML/CSS/JS. 빌드 도구 없음. 진입점은 `index.html` 단일 파일
- `words-ko.js` — 앞글자 공유 압축(front coding)으로 담은 낱말 31만 개. 1.66MB(gzip 약 812KB), 디코딩 약 150ms. 디코딩은 첫 1회만 하고 결과 `Set`을 재사용
- 사전 로드는 `<script>` 동적 삽입 + `requestIdleCallback`. 실패해도 예외로 게임이 멈추지 않음
- 브라우저 저장소(`localStorage`)를 쓰지 않습니다
- 온라인 대결은 단어를 **낸 쪽만** 유효성을 검사하고 통과한 단어만 전송합니다. 받는 쪽은 재검증하지 않으므로, 한쪽만 확장 사전이 준비된 상태여도 안전합니다
