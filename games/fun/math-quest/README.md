# ⚔️ Math Quest — 숫자의 모험

문제를 푸는 게임이 아니라, **모험을 계속하려고 문제를 푸는** 성장형 수학 RPG.
정답 = 공격, 오답 = 피격. 콤보를 쌓으면 필살기가 터지고, 몬스터를 잡으면 상자가 떨어진다.

`index.html` 만 열면 바로 플레이된다(서버·빌드 필요 없음).

## 핵심 규칙

- **정답 = 공격.** 데미지는 `공격력 비율 × 콤보 배율 × (치명타 2배) × (필살기 3배)`.
- **오답/시간초과 = 피격.** 보호막이 있으면 한 번 막아 준다.
- **콤보**가 3·5·8·12·20에서 경험치 배율이 ×1.5 → ×2 → ×3 → ×5 → ×10 으로 커지고,
  **5콤보마다 필살기**가 터진다.
- 이기면 체력이 가득 찬다. 져도 잃는 건 그 판의 보상뿐이라 부담 없이 다시 도전한다.

## 적응형 난이도

`js/difficulty.js` 한 곳에서만 결정한다.

- 최근 **20문제**의 정답률과 "제한시간 대비 걸린 시간"을 본다.
- 95% 이상 & 빠름 → **+3**, 85% 이상 → +1~2, 72~85% → **유지**, 55% 아래 → -1~-3.
- 지역 기준 난이도에서 `-24 ~ +22` 를 벗어나지 않게 붙잡아 둔다.
- 시작할 때 **실력 시험 5문제**(난이도 5·14·26·40·58)로 출발점을 잡는다.

## 캐릭터

- **레벨/EXP/골드/보석/스킬포인트** — 스킬포인트는 가방에서 공격·방어·체력·문제 시간·행운에 쓴다.
- **분야별 능력치 5종**(연산·도형·논리·추리·확률)이 따로 레벨업해서 캐릭터에 개성이 생긴다.
- 장비는 빈 칸이면 자동 장착, 중복이면 골드로 바뀐다.

## 새 내용 추가하기

| 추가할 것 | 고칠 파일 |
|---|---|
| 새 문제 유형 | `js/gen/*.js` 에 `MQ.Gen.register(id, meta, fn)` 한 덩어리. 규칙은 `js/gen/_CONTRACT.md` |
| 새 지역·몬스터 | `data/regions.js` 의 `REGIONS` 배열에 한 덩어리 |
| 새 장비·펫 | `data/items.js` 의 `ITEMS` 에 `I(...)` 한 줄 |
| 새 업적 | `data/achievements.js` 의 `A(...)` 또는 `tier(...)` 한 줄 |
| 새 던전 | `data/regions.js` 의 `DUNGEONS` 에 한 줄 |
| 밸런스 | `js/player.js`(성장 곡선) · `js/battle.js`(데미지) · `js/difficulty.js`(난이도) |

문제 생성기를 고쳤으면 반드시 검사기를 돌린다:

```bash
node tools/check-gen.js            # 전체
node tools/check-gen.js js/gen/arith.js 400
```

정답 유일성·보기 중복·`undefined`/`NaN`·SVG 규칙을 한 번에 잡아 준다.
