# Math Quest 문제 생성기 계약 (반드시 지킬 것)

대상: 8~13세 아이. 게임 안에서 몬스터를 때리려고 푸는 문제다.
**학년 표현 금지** ("초등 3학년" 등). 난이도는 오직 `lv`(1~100).

## 파일 형식
- 순수 ES5 브라우저 스크립트. `import`/`export`/`require` 금지. 화살표함수·let/const·템플릿리터럴 금지(ES5로 작성).
- 파일 맨 앞뒤를 IIFE로 감싼다: `(function(){ 'use strict'; ... })();`
- 전역 `MQ.Gen.register(id, meta, fn)` 로만 등록한다.

## register
```js
MQ.Gen.register('add', {
  name: '덧셈', icon: '➕', skill: 'calc', minLv: 1, maxLv: 100
}, function (lv, R) { ... return problem; });
```
- `id`: 영문 소문자·하이픈, 파일 안에서 유일.
- `skill`: 'calc'(연산) | 'shape'(도형·공간) | 'logic'(논리·추리) | 'pattern'(규칙·수열) | 'prob'(확률·경우의수) 중 하나.
- `minLv`/`maxLv`: 이 유형이 등장하는 레벨 구간.

## 반환 문제 객체
```js
{
  text: '17 + 25 = ?',        // 필수. 짧은 한 줄. HTML 허용(<b> 등). 몬스터 말풍선에 들어간다.
  sub: '',                    // 선택. 보조 줄(표·보기 나열 등). HTML 허용.
  svg: '',                    // 선택. 도형 그림. 반드시 viewBox 포함, width/height 속성 없이. 아래 규칙 참고.
  answer: '42',               // 필수. 문자열.
  choices: ['42','41','43','52'], // 필수. 정확히 4개, 모두 서로 다른 문자열, answer 포함.
  explain: '17에 25를 더하면 42예요.' // 필수. 한 줄 해설. 아이가 읽고 이해할 수 있게.
}
```

## 절대 규칙 (자동 검사됨)
1. `choices` 길이 정확히 4, 중복 없음, `answer` 포함.
2. `text`/`answer`/`explain` 에 `undefined`, `NaN`, `null`, `Infinity` 문자열이 절대 나오면 안 된다.
3. 뺄셈 결과는 음수 금지(lv 40 미만). 나눗셈은 나누어떨어지게(나머지 문제 유형 제외).
4. 정답이 유일해야 한다. 보기 중 정답이 될 수 있는 것이 2개면 안 된다.
5. 같은 `lv` 로 200번 호출해도 예외가 나지 않아야 한다.
6. 문제는 **10초 안에 판단 가능한 분량**이어야 한다. 긴 지문 금지.
7. 답이 분수면 `'3/4'`, 소수면 `'1.25'`, 시각이면 `'3:40'` 처럼 표기를 일관되게.

## 난이도 설계
`lv` 이 커질수록 자릿수·항 개수·단계 수가 늘어난다. 예:
- lv 1~10: 한 자리 / 아주 쉬움
- lv 11~25: 두 자리
- lv 26~45: 세 자리·두 단계
- lv 46~70: 분수·소수 섞임·세 단계
- lv 71~100: 올림피아드 감각, 역산·조건 추리

각 생성기 안에서 `lv` 를 구간으로 나눠 자연스럽게 어려워지게 한다.

## R (난수 도우미) — 엔진이 넣어준다
```js
R.int(a, b)      // a 이상 b 이하 정수
R.pick(arr)      // 배열에서 하나
R.sample(arr, n) // 중복 없이 n개
R.shuffle(arr)   // 섞인 새 배열
R.chance(p)      // 0~1 확률로 true
```
보기 만들 때 도우미(숫자 정답용):
```js
MQ.mkChoices(answerNumber, R, { spread: 5, min: 0, dec: 2 })
// dec 를 주면 소수 자릿수 유지. 항상 4개 문자열 배열을 돌려준다.
```
직접 만들 때는 `MQ.uniq4(answerString, [오답후보들...], R)` 를 쓰면 중복 제거 + 4개 보장.

## SVG 규칙 (도형 문제)
- `<svg viewBox="0 0 200 140">…</svg>` 형태. width/height 속성 금지(CSS가 맞춘다).
- 색은 `currentColor` 또는 `#ffd166`, `#4cc9f0`, `#f72585`, `#7bd88f` 만 사용.
- 선 두께 2~3, 글자는 `font-size="14"` `fill="#e8ecff"`.
- 배경 없음(투명).

## 톤
문제 문장은 짧고 게임스럽게. "슬라임이 사과 17개를 훔쳤어요. 25개를 더 훔치면?" 처럼 세계관을 살짝 얹어도 좋지만
문장이 길어지면 안 된다. 순수 식만 나오는 문제도 섞여야 한다.
