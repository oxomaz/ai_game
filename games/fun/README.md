# 🎈 재미용 게임

이 폴더에는 **놀이·오락 목적의 게임**을 넣습니다. (예: 액션, 퍼즐, 보드게임, 대전 게임 등)

새 재미용 게임을 만들 때도 루트 `CLAUDE.md`의 공통 규칙(단일 index.html, 모바일 우선, 폴더명 kebab-case)을 그대로 따르되, 폴더는 `games/fun/<게임이름>/` 아래에 생성합니다.

## 재미용 게임에만 적용되는 규칙

1. **설명서를 읽지 않아도 시작할 수 있어야 한다.** 첫 화면에서 버튼 하나로 바로 플레이가 시작되고, 규칙은 필요할 때만 펼쳐 보게 한다.
2. **한 판이 짧아야 한다.** 한 판 1~3분을 기준으로 잡고, 길어지는 게임은 중간에 그만둬도 아깝지 않도록 단계·라운드로 끊는다.
3. **난이도는 고를 수 있게 한다.** 어린 동생과 어른이 같은 게임을 각자 수준에서 즐길 수 있어야 한다.
4. **한 화면에서 여럿이 즐기는 모드를 우선 검토한다.** 마우스 하나·화면 하나로 2인 이상이 겨룰 수 있으면 훨씬 자주 하게 된다. (예: 숨은그림찾기의 버저 대결, SET의 이름 버튼 방식)
4-1. **멀리 있는 친구와도 겨룰 수 있게 한다.** 재미용 게임에는 `common/versus.js`로 **방 코드 온라인 대결**을 붙인다. 시작 화면에 `🌐 친구랑 온라인 대결` 버튼을 두고, 판을 만드는 코드는 `Versus.seeded()`로 감싸 양쪽이 똑같은 문제를 받게 한다.
5. **져도 기분 나쁘지 않게 만든다.** 패배 화면에서 바로 "한 번 더"를 누를 수 있게 하고, 최고 기록은 남겨서 다음에 갱신할 이유를 준다.
6. **실력·물리로 클리어하는 게임은 실제로 깰 수 있는지 검증한다.** 자동 생성 레벨을 쓰면 물리·규칙을 그대로 시뮬레이션해 모든 구간이 통과 가능한지 확인한 뒤 커밋한다. (예: 점프맵 100, 지하철 슬리더)
7. **캔버스로 그리는 게임은 모바일 성능을 확인한다.** 화면 밖 요소는 그리지 않고(컬링), 좁은 화면에서 60fps가 나오는지 본 뒤 커밋한다.

## 공통 UI

- 시작 화면과 결과 화면에는 `← 게임 목록` 링크(`<a class="hub-link" href="../../../">`)를 둔다. 게임 중에는 표시하지 않아 조작을 방해하지 않는다.
