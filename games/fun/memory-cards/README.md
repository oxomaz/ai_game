# 🧠 메모리 카드

카드팩을 골라 짝을 맞추는 **교육형 메모리게임**입니다.
짝을 맞히면 그 카드에 대한 설명이 팝업으로 나와서, 놀면서 저절로 외워집니다.
카드팩 파일만 추가하면 새로운 주제가 계속 생기는 구조로 만들었습니다.

👉 플레이: <https://oxomaz.github.io/jerry-games/games/fun/memory-cards/>

## 카드팩 7종

| 팩 | 장수 | 짝 맞추기 방식 |
|---|---|---|
| 🌍 세계 국기 | 120 | 국기↔국기 · 국기↔나라 이름 · **국기↔수도** |
| 🐾 동물 친구들 | 48 | 그림↔그림 · 그림↔이름 |
| 🍽️ 맛있는 음식 | 40 | 그림↔그림 · 그림↔이름 |
| 🚗 신나는 탈것 | 35 | 그림↔그림 · 그림↔이름 |
| 🎻 악기 나라 | 28 | 그림↔그림 · 그림↔이름 · 이름↔특징 |
| ⚽ 스포츠 한마당 | 40 | 그림↔그림 · 그림↔이름 · 이름↔특징 |
| 🔤 영어 단어 | 64 | 그림↔영어 · 영어↔뜻 · 그림↔그림 |

### 그림은 어떻게 그려지나 (중요)

- **국기 — 실제 국기 이미지 파일** `packs/flags/<나라코드>.svg` 120장.
  국기 이모지(🇰🇷)를 쓰면 **윈도우에서는 국기가 안 그려지고 "KR" 글자로 보입니다.** 그래서 이미지를 씁니다.
  문양이 아주 복잡한 9개 나라(세르비아·볼리비아·멕시코·스페인·에콰도르·과테말라·크로아티아·도미니카공화국·바티칸)만 `.png`.
- **악기 — SVG로 직접 그린 그림 28장.** 쓸 수 있는 악기 이모지가 🎹🎸🎺🎻🥁 정도뿐이고 국악기는 아예 없어서
  전부 그렸습니다. 피아노 건반, 하프의 줄, 장구의 모래시계 모양, 가야금의 열두 줄과 안족처럼 생김새의 특징을
  살려서 한눈에 구분됩니다. 그라디언트 id 충돌을 피하려고 **단색만** 씁니다.
- **스포츠 · 영어 단어 — 이모지.** 이 둘은 윈도우에서도 잘 나오는 이모지가 넉넉해서 그림 파일이 필요 없습니다.

## 폴더

```
games/fun/memory-cards/
├── index.html          ← 엔진 + UI + 모드 전부 (단일 파일)
├── packs/
│   ├── flags.js        ← 세계 국기 120개국 데이터
│   ├── flags/          ← 실제 국기 이미지 120장 (kr.svg, jp.svg … 일부 .png)
│   ├── animals.js  foods.js  vehicles.js
│   ├── instruments.js  ← 악기 — 28가지를 SVG로 직접 그림
│   ├── sports.js       ← 운동 40가지
│   └── english.js      ← 기초 영어 단어 64개 (뜻·읽는 법 포함)
└── README.md
```

국기팩은 대륙 6분류(아시아·유럽·아프리카·북아메리카·남아메리카·오세아니아)로 묶여 있고,
짝을 맞히면 **나라 이름 · 수도 · 대륙 · 한 줄 설명**이 나옵니다.

```
🇰🇷 대한민국
수도 : 서울
대륙 : 아시아
“한류와 K-POP으로 유명한 나라”
```

## 모드

| 모드 | 설명 |
|---|---|
| 🙋 혼자 도전 | 클리어 시간 · 뒤집은 횟수 · 정확도를 재고 점수를 남깁니다 |
| 👫 둘이서 번갈아 | 한 기기에서 번갈아 뒤집기. **맞히면 한 번 더**, 틀리면 상대 차례 |
| 🌐 온라인 대결 | 방 코드로 친구와 1:1. 같은 판에서 진짜 턴제로 겨룹니다 |
| 📖 카드 도감 | 팩 전체를 표로 보며 미리 외우기. 검색 · 대륙별 보기 지원 |

## 판 크기

| 이름 | 배치 | 쌍 |
|---|---|---|
| 아주 쉬움 | 3×4 | 6 |
| 쉬움 | 4×4 | 8 |
| 보통 | 4×6 | 12 |
| 어려움 | 6×6 | 18 |
| 도전 | 6×8 | 24 |

카드 수가 부족한 팩은 가능한 크기만 나옵니다(지금은 7개 팩 모두 24쌍까지 됩니다).

## 점수

```
점수 = 쌍 × 40                     (기본)
     + 쌍 × 60 × 정확도            (정확도 = 맞힌 짝 ÷ 시도 횟수)
     + max(0, 쌍×12초 − 걸린시간) × 3   (빠를수록 보너스)
```

- 둘이서 · 온라인은 **내가 모은 짝 × 100** 점으로 기록합니다.
- 온라인 순위표에 올라가는 모드는 **`세계 국기 · 국기 ↔ 나라 이름 · 보통`** 하나입니다.
  (서버 순위표가 게임당 하나뿐이라 난이도·주제가 섞이면 순위가 무의미해집니다)

## 조작

- 카드를 **누르면 뒤집힙니다.** 두 장이 짝이면 열린 채로 남고, 아니면 1초 뒤 닫힙니다.
- 시작 화면에서 🔊 효과음 · 🎵 배경음악 · 🌙 다크모드를 켜고 끌 수 있습니다(선택은 기억됩니다).
- 게임 중 위쪽 🔊 🎵 ✕ 버튼으로 소리를 끄거나 나갈 수 있습니다.

## 새 카드팩 추가하기 (2단계)

1. `packs/<이름>.js` 파일을 하나 만들고 `window.MemoryPacks.add({...})` 로 데이터를 넣습니다.
2. `index.html` 의 카드팩 `<script>` 목록에 한 줄 추가합니다.

```js
window.MemoryPacks.add({
  id: 'flags',
  title: '세계 국기',
  emoji: '🌍',
  desc: '120개국의 국기 · 수도 · 대륙을 카드로',
  back: ['#a5d8ff', '#d0bfff'],          // 카드 뒷면 그라데이션 두 색
  groups: [{ id: 'as', title: '아시아' }],   // (선택) 도감에서 나눠 볼 묶음
  modes: [                                  // 어떤 짝 맞추기를 지원하는가
    { id: 'same', title: '국기 ↔ 국기', a: 'img', b: 'img', hint: '같은 국기 두 장 찾기' },
    { id: 'cap',  title: '국기 ↔ 수도', a: 'img', b: 'capital' }
  ],
  picField: 'img',                          // 팝업·도감에서 쓸 대표 그림
  fields: {                                 // 그 필드를 카드에 어떻게 그리는가
    img:     { style: 'img' },              // img = 이미지 파일
    capital: { style: 'text' }              // text = 굵은 글씨 (icon:true 면 위에 이모지도)
  },
  info: function (c) {                      // 짝을 맞혔을 때 뜨는 팝업
    return { head: c.name, rows: [['수도', c.capital]], note: c.note };
  },
  cards: [
    { key: 'KR', group: 'as', img: 'packs/flags/kr.svg', name: '대한민국', capital: '서울', note: '…' }
  ]
});
```

- **`key` 가 같은 두 장이 짝**입니다. 팩 안에서 `key` 는 겹치면 안 됩니다.
- 카드 그리는 스타일 5가지

  | style | 무엇을 그리나 | 쓰는 팩 |
  |---|---|---|
  | `glyph` | 큰 이모지 (`card.glyph`) | 동물 · 음식 · 탈것 |
  | `img`   | 이미지 파일 (`card.img`) | 국기 |
  | `art`   | 팩이 넣어둔 SVG 문자열 (`card.art`) | 악기 |
  | `text`  | 굵은 글씨 (`icon:true` 면 위에 이모지도) | 이름 · 수도 · 영어 단어 카드 |
  | `sub`   | 작은 설명 글씨 | 특징 카드 |

- `picField` 에 대표 그림 필드를 적어 두면 **정보 팝업과 도감 목록**이 그 그림을 씁니다.
- 이미지를 못 불러오면 자동으로 이름 글자로 대체됩니다(오프라인·파일 누락 대비).
- 글자 카드는 글자 수에 맞춰 글씨 크기가 자동으로 줄어듭니다.

## 기술 메모

- **외부 라이브러리 0.** HTML + CSS + JS 만. 온라인 대결만 저장소의 `common/versus.js`(+ `peerjs.min.js`)를 씁니다.
  국기 이미지도 **저장소 안에** 있어서 인터넷 없이도 그대로 나옵니다(그림 자료 전체 약 780KB).
- 카드팩을 `.json` 이 아니라 `.js` 로 둔 이유: `fetch('*.json')` 은 `file://` 로 열면 CORS 로 막혀서
  바탕화면에서 `index.html` 을 더블클릭하면 게임이 안 켜집니다. `.js` 는 어디서 열어도 동작합니다.
- **효과음·배경음악은 WebAudio 로 직접 합성**합니다. 음원 파일이 없어 용량 0, 저작권 문제 0.
- 자료 출처: 국기 이미지 [flag-icons](https://github.com/lipis/flag-icons) (MIT). 악기 그림은 직접 그렸습니다.
- 카드 칸 크기는 JS 가 화면 크기·가로/세로에 맞춰 계산합니다. **320×568 에서도 24쌍(6×8) 판이 스크롤 없이** 다 보입니다.
- 온라인 대결은 `Versus.seeded()` 로 배치를 맞추고 **뒤집은 좌표만 주고받습니다.** 판정은 양쪽이 각자 하므로 보드가 어긋나지 않습니다.
  상대 메시지는 카드 공개 애니메이션이 끝난 뒤 순서대로 처리하는 **대기줄**을 거칩니다(공개 중에 무시되면 어긋납니다).
- 기록·배지는 `common/profile.js`(전역 `JG`) 하나로 모읍니다. 게임이 자체 `localStorage` 기록을 만들지 않습니다.
- 자동 테스트용 훅: `window.MCTest.state()` 로 현재 판 상태를 볼 수 있습니다.
