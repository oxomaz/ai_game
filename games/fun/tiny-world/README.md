# 🌳 Tiny World ― 세계수와 정령의 섬

작은 섬을 돌아다니며 자원을 모으고, 도구와 건물을 만들고, 귀여운 정령을 친구로 만들어
**세계수를 4단계까지 키우는** 2D 탐험·채집·제작·건설·수집 게임입니다. (8~11세)

👉 플레이: `games/fun/tiny-world/` — 모바일·PC 웹브라우저 모두 지원, 서버 없이 실행됩니다.

---

## 놀이 방법 (핵심 루프)

```
탐험 → 자원 발견 → 직접 채집 → 도구·건물 제작 → 퀘스트 완료
   → 경험치·보상 → 나와 정령 성장 → 세계수 성장 → 새 지역 해금 → 더 희귀한 자원·정령
```

- 처음 1분: 나무·돌 채집 → 첫 퀘스트 완료
- 5분 안: 작업대·나무 도끼 제작 → 세계수 2단계 → 작은 숲 해금
- 10분 안: 작은 집·텃밭 완성, 첫 정령 친구

## 조작법

| | PC | 모바일 |
|---|---|---|
| 이동 | 방향키 · WASD | 화면 왼쪽 가상 패드 |
| 채집·사용 | `Space` · `E` (누르고 있으면 계속 채집) | 오른쪽 큰 버튼 (길게 누르면 계속) |
| 가까운 대상 바로 사용 | 맵 클릭 | 맵 터치 |
| 메뉴 | 아래 버튼 클릭 | 아래 버튼 터치 |
| 닫기 / 건설 취소 | `Esc` | 취소 버튼 |

퀘스트 칸을 누르면 접혀서 화면이 넓어집니다. (가로 모드에서는 자동으로 접힙니다)

## 섬 구조 (24 × 30 타일)

| 지역 | 해금 | 특징 |
|---|---|---|
| 시작 평원 | 처음부터 | 집터 · 세계수 · 연못 · 나무 · 돌 · 풀 · 꽃 |
| 작은 숲 | 세계수 2단계 | 나무 많음 · 버섯 · 열매 · **잎새 정령** |
| 바위 언덕 | 세계수 3단계 | 돌 · 철광석(돌 곡괭이 필요) · **돌멩이 정령** |
| 별빛 해안 | 세계수 4단계 | 별돌 · 다음 세계로 가는 문 |

잠긴 지역은 안개로 가려지고 들어갈 수 없습니다. 자원 배치는 고정 씨앗(`TW.MAP.SEED`)이라
누가 해도 같은 섬이 나오고, **해금 단계마다 길이 막히지 않는지 자동으로 검사**해서 배치합니다.

## 자원과 도구

- 자원: 나무 · 돌 · 풀 · 열매 · 버섯 · 철광석 · 꽃 · 물 · 씨앗
- 특별: 별돌 ☄️ · 무지개꽃 🌺 · 황금 나무 ✨ (랜덤 사건으로만 등장)
- 도구: 나무 도끼 / 나무 곡괭이 / 돌 도끼 / 돌 곡괭이
  - 도구는 **자동으로 가장 좋은 것이 쓰입니다.** 등급이 높으면 획득량 +1~2, 채집 속도 ↑
  - 철광석은 **돌 곡괭이**가 있어야 캘 수 있습니다 (🔒 표시)
- 채집하면 자원이 흔들리고 효과음·획득 표시·경험치가 뜨며, 일정 횟수 뒤 사라지고 시간이 지나면 다시 자랍니다.

## 건물 (빈 타일을 골라 설치)

| 건물 | 해금 | 기능 |
|---|---|---|
| 🛠️ 작업대 | Lv.1 | 도구 제작 |
| 🏠 작은 집 | Lv.1 | 활동력 가득 회복 |
| 🌾 텃밭 | Lv.2 | 씨앗 심고 → 물 주고 → 수확 |
| 📦 창고 | Lv.3 | 가방 용량 +150 |
| 🏕️ 정령 쉼터 | Lv.3 | 정령 일자리 +2 |

건설 버튼을 누르면 놓을 수 있는 칸이 하얗게 반짝입니다.

## 정령 4종

| 정령 | 발견 조건 | 선물 | 능력 |
|---|---|---|---|
| 🍃 잎새 정령 | 나무 10번 채집 + 숲 해금 | 열매 3 | 나무 자동 수집 |
| 🪨 돌멩이 정령 | 돌 15번 채집 + 언덕 해금 | 돌 10 | 돌 자동 수집 |
| 💧 물방울 정령 | 텃밭에 물 5번 주기 | 꽃 2 | 텃밭 성장 1.8배 |
| 🔥 불씨 정령 | 세계수 2단계 + 에너지 12 | 버섯 3 | 제작 시간 1/3 |

- **뽑기가 없습니다.** 조건을 만족하면 정령이 맵에 나타나고, 말을 걸어 선물을 주면 친구가 됩니다.
- 잡거나 공격하는 방식은 없습니다.
- 친구가 된 정령은 건물에 배치해 일을 맡기거나, 그냥 같이 다닐 수 있습니다.
- 자동 수집은 30~34초에 1개로 **일부러 느립니다.** 직접 탐험하는 게 훨씬 빠릅니다.
- 함께 다니고 함께 일하면 친밀도·레벨이 오르고, 일하는 속도가 조금 빨라집니다.
- 진화 단계(`evo`)는 데이터로 준비돼 있습니다. (예: 씨앗 정령 → 새싹 정령 → 잎새 정령 → 숲의 수호자)

## 세계수

에너지를 모아 4단계까지 키우는 것이 최종 목표입니다. 단계마다 모습이 완전히 달라집니다.

| 단계 | 모습 | 필요 누적 에너지 | 보상 |
|---|---|---|---|
| 1 | 씨앗 🌰 | – | – |
| 2 | 작은 새싹 🌱 | 8 | 작은 숲 해금 |
| 3 | 어린 나무 🌳 | 26 | 바위 언덕 해금 |
| 4 | 빛나는 나무 🌟 | 58 | 별빛 해안 + 다음 세계의 문 |

에너지는 **퀘스트 완료 · 건물 완성 · 정령 친구 · 자원 봉헌**으로 얻습니다.
(꽃 1개 = 1, 나무·돌 3개 = 1, 철광석 1개 = 3, 별돌 1개 = 6 …)

## 퀘스트

22개가 순서대로 열리고, 한 번에 최대 3개만 보여 줍니다. 문장은 짧게, 첫 번째 목표에는 힌트가 붙습니다.
조건을 만족하면 자동으로 완료되고 보상이 바로 나옵니다.

## 랜덤 사건

황금 나무 🌟 · 무지개꽃 🌈 · 유성(별돌) ☄️ · 보물상자 🎁 · 비(텃밭 2배) 🌧️ · 정령의 선물 🎁
— 55~110초마다 하나. **손해는 절대 없고 보너스만 있습니다.**

## 어린이 UX 원칙

- 전투 없음 · 광고 없음 · 결제 없음 · 채팅 없음 · 로그인 없음
- 자원을 모두 잃거나 처음부터 다시 시작하는 시스템 없음
- 활동력은 5초에 1씩 자동 회복 (집에서 쉬거나 열매·버섯을 먹어도 회복)
- 실수해도 손해가 없고, 저장 초기화는 두 번 확인
- 항상 지금 할 일이 화면 위에 보임

## 저장

`localStorage` 키 `tinyWorld_v1` 하나에 10초마다 자동 저장 (탭을 옮기거나 닫을 때도 저장).
저장이 막힌 브라우저에서는 메모리 저장으로 자동 대체되며 게임은 그대로 돌아갑니다.
시작 화면의 `이어하기`, 설정의 `저장 지우고 새로 시작`으로 관리합니다.

## 기록·배지 (common/profile.js)

- 시작 화면의 **플레이어 칩**으로 누가 하는지 고릅니다. 플레이어마다 기록·배지가 따로 쌓입니다.
- 판이 끝나는 개념이 없으므로 **섬 점수**가 오를 때마다 내 최고 기록을 갱신합니다.
  `섬 점수 = 세계수 단계×150 + 레벨×30 + 정령 친구×80 + 건물×15 + 퀘스트×20 + 도감%×3`
- **온라인 순위표는 쓰지 않습니다.** 남과 점수를 겨루는 게임이 아니라 내 섬을 키우는 게임이라,
  기록은 내 기기에만 남습니다. (`profile.js` 의 `RANKED` 에 등록하지 않았습니다)
- 배지 6종: 첫 도구 · 첫 집 · 첫 정령 · 정령 4종 · 세계수 4단계 · 도감 100%

### 새 내용 추가하기

| 추가할 것 | 고칠 파일 |
|---|---|
| 아이템 · 자원 노드 | `data/items.js` (`TW.ITEMS` / `TW.NODES`) |
| 제작법 | `data/recipes.js` |
| 건물 | `data/buildings.js` + `sprites.js` 의 `building()` |
| 정령 | `data/spirits.js` (`TW.SPIRITS` · `SPIRIT_UNLOCK` · `SPIRIT_HINT`) + `sprites.js` 의 `spirit()` |

## 기술 메모

- 순수 HTML/CSS/JS. 빌드 도구·외부 라이브러리 없음. ES 모듈을 쓰지 않아 `file://` 로 열어도 동작.
- 그림은 전부 캔버스 도형으로 직접 그린 오리지널 아트 + 이모지. 외부 저작권 이미지 없음.
- 효과음은 Web Audio API 로 실시간 합성. 음원 파일 없음. 설정에서 끌 수 있음.
- 모바일: `--jg-vh` · `viewport-fit=cover` · `env(safe-area-inset-*)`. 320px 폭에서 가로 스크롤 0.
- 타일 크기는 화면에 맞춰 가로 9칸 정도가 보이도록 자동 조절(30~64px).
- 자원 배치는 해금 단계별로 도달 가능성을 검사해 막힌 길을 자동으로 뚫습니다(`TW.ensureConnected`).
