# 🔤 끝말잇기

앞사람이 말한 단어의 **마지막 글자로 시작하는 단어**를 이어 말하는 고전 단어 게임입니다.
컴퓨터와 1:1로 겨루거나, 한 화면에서 최대 8명이 돌아가며 즐길 수 있습니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/fun/kkeutmalitgi/**

## 모드

### 컴퓨터와 대결

- **쉬움 / 보통 / 어려움** 3단계
- 난이도가 올라갈수록 컴퓨터가 이어가기 어려운 글자를 남기도록 단어를 고릅니다
- 먼저 시작하는 쪽을 **나 / 컴퓨터 / 랜덤** 중에서 선택

### 여러 명이서 함께

- 최대 **8명**까지 이름을 입력하고 한 화면에서 순서대로 진행
- **순서 랜덤 섞기** 지원 — 시작 전에 차례를 섞을 수 있습니다
- 자기 차례에 단어를 못 내면 탈락, 마지막까지 남은 사람이 승리

## 규칙 옵션

- **제한 시간** — 한 턴에 15초씩, 또는 시간 제한이 없는 **자유 모드**
- **내장 사전에 없는 단어도 허용** — 체크하면 사전에 없는 단어도 통과시켜, 아이들과 느슨하게 즐길 때 좋습니다
- 이미 나온 단어는 다시 쓸 수 없고, 이어진 단어 수가 기록됩니다

## 조작

키보드로 단어를 입력하고 `Enter`. 모바일에서는 화면 입력창을 사용합니다.

## 기술 메모

- 단일 HTML 파일, 한국어 단어 사전을 파일 안에 내장
- 브라우저 저장소를 쓰지 않습니다

## 🌐 친구랑 온라인 대결

시작 화면의 **🌐 친구랑 온라인 대결** 버튼으로 방을 만들거나, 친구가 알려준 **4글자 방 코드**를 넣어 입장한다.
두 사람은 같은 시드로 **완전히 똑같은 판**을 받아 각자 플레이하고, 위쪽 VS 바에서 상대 점수가 실시간으로 보인다.
서버는 없다 — 브라우저끼리 직접 연결(WebRTC/P2P)하고, 연결 중개만 PeerJS 공개 서버를 쓴다. 공용 코드는 `common/versus.js`.

방장이 선공으로 번갈아 단어를 잇는다. 내 차례에만 입력창이 열리고, 시간을 넘기거나 포기하면 진다.
