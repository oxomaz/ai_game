# 🃏 SET 카드게임

카드 세 장의 각 특징이 **셋 다 같거나 셋 다 다르면** SET! 눈이 빨라지는 패턴 찾기 게임입니다.

## 모드

| 모드 | 설명 |
|---|---|
| 👨‍👧 2인 대전 | 자기 이름 버튼(또는 키보드 Q / P)을 먼저 누른 사람이 카드를 고릅니다 |
| 🧘 혼자 연습 | 시간을 재면서 덱을 모두 비웁니다 |
| 🌐 온라인 대결 | 똑같은 판을 보고 누가 먼저 찾는지 겨룹니다 (`common/versus.js`) |
| 🎓 연습 문제 | SET인지 아닌지 맞히는 5문제 튜토리얼 |

## 규칙 / 난이도

- 카드의 특징은 **색깔**(빨강·초록·보라), **모양**(마름모·물결·타원), **개수**(1·2·3), **무늬**(꽉 참·줄무늬·비어 있음).
- 세 장을 고를 때 각 특징이 **모두 같거나 모두 달라야** SET입니다. 두 개만 같으면 아닙니다.
- 🌱 쉬움(27장) — 무늬는 모두 같아서 색·모양·개수 3가지만 보면 됩니다.
- 🔥 정식(81장) — 무늬까지 4가지 모두 맞춰야 합니다.
- 💡 힌트는 세 단계(한 장 → 두 장 → 세 장)로 알려주고, 🙅 "SET 없어요"가 맞으면 카드 세 장을 더 깝니다.

## 조작법

카드를 눌러 세 장을 고르면 바로 판정합니다. 2인 대전은 이름 버튼(Q / P)을 먼저 눌러야 카드를 고를 수 있고, 제한 시간 안에 못 맞히면 3초 동안 쉽니다. `H`는 힌트, `ESC`는 창 닫기.

## 기록 · 배지

- 상단 프로필 칩에서 플레이어를 바꾸면 기록이 사람별로 따로 쌓입니다 (`common/profile.js`).
- 기록은 모드·난이도별로 따로 저장됩니다: `혼자 · 쉬움`(걸린 시간, 짧을수록 좋음) · `2인 대전 · 정식`(한 판에 찾은 SET 개수) · `온라인 대결`.
- 배지: 🃏 `set-clear`(한 판 완주) · 🧠 `set-12`(한 판에 12개) · 💡 `set-nohint`(힌트 없이 완주).

## 기술 메모

- 단일 `index.html` (외부 라이브러리 없음). 카드 그림은 SVG로 직접 그리고, 소리는 WebAudio로 만듭니다.
- `layoutBoard()`가 보드 위·아래 UI 높이를 실제로 재고 `--jg-vh`(보이는 화면 높이)를 이용해 **열 수와 카드 크기를 함께** 고릅니다.
  카드가 몇 장이든(9 ~ 21장) 스크롤 없이 한 화면에 들어오고, 가로 스크롤이 생기지 않습니다.
- 가로모드(높이 ≤ 470px)에서는 메시지와 버튼을 한 줄로 배치해 카드가 쓸 세로 공간을 넓힙니다.
- 온라인 대결은 방장이 심판이 되어(`sreq` → `sgo`/`sno`) 두 사람의 판이 어긋나지 않게 맞춥니다.
- 저장은 localStorage 한 곳뿐이며, 막혀 있으면 자동으로 메모리 저장으로 대체되고 게임은 그대로 진행됩니다.
