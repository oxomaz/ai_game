# 🃏 SET 카드게임

펼쳐진 카드 중에서 조건에 맞는 **세 장의 조합(SET)** 을 찾아내는 패턴 인식 게임입니다.
규칙을 처음 접해도 되도록 설명과 연습 문제부터 시작합니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/fun/set/**

## 규칙

카드마다 **색깔 · 모양 · 개수 · 무늬** 네 가지 속성이 있습니다.
세 장을 골랐을 때 **네 속성이 각각 "셋 다 같거나, 셋 다 다르면"** 그 세 장이 SET입니다.

> 예) 색이 전부 빨강이고 · 모양이 전부 다르고 · 개수가 전부 2개고 · 무늬가 전부 다르다 → SET ⭕
> 색이 빨강·빨강·초록이면 (둘만 같음) → SET ❌

## 진행

1. **규칙 설명** — 네 가지 속성과 판정 기준을 그림으로 안내
2. **연습 문제** — "이 세 장은 SET일까요?" ⭕ / ❌ 로 감을 잡습니다
3. **본 게임 시작**

## 모드

- **혼자 연습** — 찾은 SET 개수와 걸린 시간을 기록
- **2인 대결** — 각자 자기 이름 버튼을 누른 뒤 세 장을 고르는 방식. 한 화면·한 마우스로 대결할 수 있습니다

## 기능

- **힌트** — 사용 횟수가 함께 표시됩니다
- **"SET 없어요" 선언** — 더 찾을 조합이 없다고 판단되면 선언해 다음 카드로 넘어갑니다 (실제로 없으면 통과)
- 게임 종료 시 찾은 SET 개수 · 걸린 시간 요약

## 조작

카드 세 장을 클릭 또는 터치.

## 기술 메모

- 단일 HTML 파일, 카드 도형은 SVG로 직접 렌더링
- 브라우저 저장소를 쓰지 않습니다
