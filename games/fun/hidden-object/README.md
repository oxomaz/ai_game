# 🔍 숨은그림찾기

수십~수백 개의 귀여운 그림이 흩뿌려진 그림판에서 위에 뜬 **목표 그림**을 찾아 클릭하는 게임. 그림은 전부 코드로 그리는 SVG라 이미지 파일이 하나도 없고, 매판 색·크기·각도가 달라져서 같은 판이 두 번 나오지 않아요.

## 모드

| 모드 | 설명 |
| --- | --- |
| 🧡 혼자 하기 | 제한시간 안에 최고점 도전. 힌트는 라운드당 1번 |
| 💙 둘이서 대결 | 한 화면을 함께 보다가 먼저 **버저**를 누르고 4초 안에 클릭. 틀리면 감점 |
| 🌐 친구랑 온라인 대결 | `common/versus.js`로 방을 만들어 **똑같은 그림판**에서 각자 찾고 점수로 승부 |

## 규칙 / 난이도

- 목표 칩에 있는 그림을 그림판에서 찾아 클릭하면 **+100점**.
- 엉뚱한 곳을 클릭하면 혼자 하기 `-20점 · -3초`, 대결에서는 `-40점`.
- 힌트는 `-40점`, 라운드당 1번 (`H` 키).
- 라운드를 다 클리어하면 남은 시간 × 5점의 **시간 보너스**.
- **제한시간 끄기**를 고르면 쫓기지 않고 천천히 찾을 수 있어요. 시간 보너스는 없고 걸린 시간만 세어줘요. 게임 중에도 위쪽 `⏱` 버튼으로 바꿀 수 있어요.

| 난이도 | 목표 | 그림 수 | 회전 | 색 흔들기 | 제한시간 |
| --- | --- | --- | --- | --- | --- |
| 쉬움 🐣 | 3개 | 30 | ±12° | ±6 | 80초 |
| 보통 🐱 | 4개 | 58 | ±40° | ±13 | 65초 |
| 어려움 🔥 | 5개 | 95 | ±130° | ±20 | 55초 |
| 악몽 💀 | 6개 | 140 | ±180° | ±28 | 48초 |

라운드가 올라갈수록 그림 수가 조금씩 늘어나요. 라운드 수는 3 · 5 · 7판 중에서 고를 수 있어요.

## 조작법

- 그림판을 **클릭 / 터치**해서 목표를 찾아요.
- 둘이서 대결: 1P `Q` · 2P `P` (터치는 아래 버저 버튼).
- `H` 힌트, `Esc` 나가기.

## 기록 · 배지

시작 화면 위쪽의 **프로필 칩**에서 플레이어를 고르거나 새로 만들 수 있어요. 기록과 배지는 플레이어별로 따로 쌓입니다 (`common/profile.js`, 이 브라우저의 localStorage에만 저장).

- **기록**: 최종 **점수**(`점`), 높을수록 좋음. mode는 `보통 · 5판 · 제한시간`처럼 난이도·라운드·제한시간 설정을 묶어 저장해요.
  - 제한시간을 켜면 남은 시간이 보너스로, 끄면 빨리 찾을수록 감점이 줄어 결국 점수에 시간이 녹아 있어요. 그래서 한 게임에 잣대를 하나(점수)만 써서 설정이 다른 판끼리 기록이 섞이지 않게 했습니다.
  - 온라인 대결은 `온라인 대결`로 따로 모으고, 한 화면 2인용 **둘이서 대결**은 개인 기록이 아니라서 저장하지 않아요.
- **배지**: `ho-clear`(모든 라운드 클리어) · `ho-fast`(한 라운드를 30초 안에 클리어) · `ho-nomiss`(헛클릭 0회로 전 라운드 클리어)
- 온라인 대결 닉네임 칸은 현재 플레이어 이름으로 자동으로 채워져요.

## 기술 메모

- 단일 `index.html` (HTML/CSS/JS). 외부 라이브러리·빌드 도구 없음. 그림 40여 종은 0~100 좌표계 SVG 문자열 함수로 정의돼 있어요.
- `common/profile.js`(플레이어·기록·배지)와 `common/versus.js`(온라인 대결)를 함께 불러와요.
- 배치는 격자를 만들어 섞은 뒤 각 칸 안에서 위치를 흔드는 방식이라, 그림이 겹쳐 뭉치지 않으면서도 매번 달라져요.
- **모바일에서 그림판이 잘리지 않게** 하는 방법:
  - `#game`은 세로 flex 한 덩어리이고 `overflow:hidden`. 위쪽 바·목표 칩·버저는 `flex:0 0 auto`, 그림판(`#stageWrap`)만 `flex:1 · min-height:0`으로 남는 공간을 전부 가져가요.
  - 목표 칩 목록은 `max-height`로 제한하고 안에서만 스크롤돼서, 목표가 6개여도 그림판을 밀어내지 않아요.
  - 장면을 만들 때 **실제로 보이는 상자 크기를 재서** viewBox 비율을 거기에 맞춰요. 그래서 어떤 화면 비율에서도 여백 없이 딱 들어맞고, 클릭 좌표는 `getScreenCTM().inverse()`가 알아서 보정하므로 스케일이 바뀌어도 판정이 어긋나지 않아요. (온라인 대결만 양쪽 그림을 같게 하려고 높이를 760으로 고정)
  - 높이는 `var(--jg-vh)`, 안전영역은 `env(safe-area-inset-*)`. 화면이 내용보다 짧을 때 위가 잘리지 않도록 `justify-content:safe center`를 씁니다.
  - 320px 폭 전용, 가로모드(높이 440px 이하) 전용 미디어쿼리가 따로 있어요.
