# 🚇 지하철 슬리더

승객을 태워 편성을 늘리고, 다른 열차와 부딪히지 않게 피해 다니는 **slither.io 방식의 지하철 게임**입니다.
지렁이 대신 지하철 열차가 달리고, 몸통이 길어질수록 편성 칸수가 늘어납니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/fun/subway-io/**

## 진짜 지하철처럼 보이게

캔버스로 직접 그린 화면에 실제 서울 지하철의 특징을 담았습니다.

| 요소 | 어떻게 보이나 |
|---|---|
| **편성** | 동그란 몸통이 아니라 **네모난 차량**이 줄줄이 이어집니다. 맨 앞·맨 뒤는 운전실이 있는 **선두차**, 가운데는 객차입니다 |
| **연결 통로** | 차량과 차량 사이에 **주름막(幌)** 이 그려집니다 |
| **창문 · 승객** | 옆면에 줄지어 난 네모 창문. **승객을 많이 태울수록 창문 안에 사람이 더 많이 비칩니다** — 굳이 숫자를 안 봐도 상대가 얼마나 찼는지 보입니다 |
| **출입문** | 차량 한 칸마다 **출입문 4개**. 가운데 여닫이 이음선까지 있습니다 |
| **노선색 띠** | 실제 전동차처럼 차체 옆면을 **노선색 띠**가 지나갑니다 (은색 스테인리스 차체 + 노선색 띠) |
| **행선지 표시기** | 선두차 앞쪽에 `급행 강남행` 같은 **LED 전광판**. 등급도 여기 같이 뜹니다 |
| **선두차 얼굴** | 앞유리 · 전조등(흰색) / 맨 뒤 칸은 **후미등(빨간색)** |
| **지붕** | 지붕 마루를 따라 **냉방장치**가 얹혀 있습니다 |
| **역** | **승강장 + 노란 점자블록(안전선) + 스크린도어**, 그리고 흰 바탕에 굵은 한글 · 작은 영문 · 노선색 동그라미 안 역번호가 들어간 **역명판** |
| **미니맵** | 점 찍힌 지도가 아니라 **실제 노선도 스타일** — 굵은 직선과 45° 꺾임, 역은 흰 동그라미 |

노선색은 실제 값을 그대로 씁니다 (1호선 `#0052A4`, 2호선 `#00A84D`, 3호선 `#EF7C1C`, 4호선 `#00A5DE`, 5호선 `#996CAC`, 6호선 `#CD7C2F`, 7호선 `#747F00`, 8호선 `#E6186C`, 9호선 `#BDB092` …).

## 열차 고르기

시작 전 두 단계로 내 열차를 정합니다.

**1단계 — 노선 18종** (실제 노선색 그대로)

1~9호선 · 신분당선 · 공항철도 · 경의중앙선 · 수인분당선 · 우이신설선 · GTX-A · 인천1호선 · 부산1호선 · 대구1호선

**2단계 — 열차 등급 7종**

| 등급 | 겉모습 | LED 표시 |
|---|---|---|
| 일반열차 | 노선색 띠만 두른 기본 전동차 | `강남행` |
| 급행열차 | 노선색 띠 아래 **빨간 줄** 하나 더 | `급행 강남행` |
| 특급열차 | 노선색 띠 아래 **금색 줄** | `특급 강남행` |
| ITX-새마을 | 밝은 차체 · **큰 창** · 붉은 줄 | `ITX 강남행` |
| KTX | 은색 차체에 **유선형 앞머리** | `KTX 강남행` |
| 무궁화호 | 크림빛 차체 · **작은 창**이 촘촘 | `무궁화 강남행` |
| 광역급행 | **각진 쐐기형 전면부** · 하늘색 줄 | `광역급행 강남행` |

> **등급은 겉모습만 다릅니다.** 속도 · 회전력 · 성장 속도는 7종 모두 완전히 동일해서, 어떤 열차를 골라도 유불리가 없습니다.

## 규칙

- 바닥에 흩어진 **승객**을 머리로 지나가며 태웁니다. 승객 5명당 편성이 1칸씩 늘어납니다 (기본 4칸 → 최대 44칸).
- **내 머리가 다른 열차의 차량에 닿으면 탈선**(게임 오버)입니다.
- 반대로 다른 열차가 내 몸통에 부딪히면 그 열차가 탈선하고, **태우고 있던 승객이 선로에 쏟아집니다.** 이걸 주워 담는 게 가장 빠르게 크는 방법입니다.
- 자기 몸통에는 부딪히지 않습니다. 마음껏 감아도 됩니다.
- 붉은 점선 바깥은 선로 끝입니다. 넘어가면 즉시 탈선합니다.
- **편성이 길어질수록 회전이 무거워집니다.** 짧을 때처럼 급하게 꺾이지 않으니 미리 돌기 시작해야 합니다.

## 부스터

가속하면 속도가 약 1.8배가 되지만 **승객이 조금씩 내립니다**(초당 4~5명). 승객이 6명 이하로 남으면 가속이 걸리지 않습니다.
상대 앞을 가로막으러 갈 때나 위험 구간을 빠져나올 때만 쓰는 게 좋습니다.

## 상대 열차

AI 열차 11대가 함께 달립니다. 이 중 절반 정도는 **'사냥꾼' 성향**이라, 자기보다 작은 열차를 발견하면 진행 방향 앞을 가로막으러 옵니다.
정면에서 다가오는 열차가 갑자기 가속하면 앞을 막으려는 신호입니다.

## 화면

- **왼쪽 위** — 현재 탑승 승객 수 · 편성 칸수 · 격파한 열차 수
- **오른쪽 위** — 실시간 순위 (상위 5대 + 내 순위)
- **오른쪽 아래** — 노선도 모양 미니맵 (내 위치는 노란 테두리, 다른 열차는 작은 네모 차량)

## 기술 메모

- 단일 HTML 파일, 캔버스 2D. 외부 라이브러리·외부 이미지 없음 (차량·역·노선도 전부 코드로 그림)
- 몸통은 이동 거리 누적값이 담긴 경로 배열을 이분탐색으로 샘플링해 그립니다
- **차량 스프라이트 캐시** — 차량 한 칸(등급 × 노선색 × 선두/객차/후미 × 혼잡도)을 오프스크린 캔버스에 딱 한 번만 그려두고, 매 프레임에는 `drawImage` 한 번씩만 합니다. 44칸 편성이 12대여도 렌더링이 가벼운 이유
- **LOD(거리별 상세도)** — 화면에서 차량 한 칸이 17px 이상이면 창문·출입문·승객·LED까지, 그보다 작으면 창 밴드만, 7.5px 아래로 내려가면 노선색 막대 하나로 그립니다
- **화면 밖 컬링** — 열차 단위뿐 아니라 **차량 한 칸 단위**로 화면 밖이면 건너뜁니다
- 측정: 44칸 편성 12대가 동시에 달리는 상태에서 프레임 간격 중앙값 16.7ms(60fps) — 900×640, 390×844(모바일) 둘 다. 렌더링 자체는 평균 1.4~1.7ms
- **충돌 판정은 차량 중심이 아니라 경로를 일정 간격으로 샘플링한 원들**로 합니다. 차량이 길어져도 틈 사이로 뚫고 지나가는 일이 없습니다
- 최고 기록만 `localStorage`에 저장하며, 저장이 막힌 환경에서는 메모리 저장으로 자동 대체됩니다
- Node에서 게임 로직을 그대로 5,000프레임 시뮬레이션해 검증했습니다 — 등급 7종의 주행 결과 완전 일치(밸런스 동일), 충돌 샘플 연속성, 자충돌 불가, 부스터 승객 소모, 성장·사망·리필 정상 동작

## 🌐 친구랑 온라인 대결

시작 화면의 **🌐 친구랑 온라인 대결** 버튼으로 방을 만들거나, 친구가 알려준 **4글자 방 코드**를 넣어 입장한다.
두 사람은 같은 시드로 **완전히 똑같은 판**을 받아 각자 플레이하고, 위쪽 VS 바에서 상대 점수가 실시간으로 보인다.
서버는 없다 — 브라우저끼리 직접 연결(WebRTC/P2P)하고, 연결 중개만 PeerJS 공개 서버를 쓴다. 공용 코드는 `common/versus.js`.

같은 맵에서 승객 수로 겨룬다. 상대 열차는 👻 유령으로 보이기만 하고 부딪히지 않는다. AI 열차는 출발할 때만 같고 그 뒤로는 각자 화면에서 따로 움직인다.
