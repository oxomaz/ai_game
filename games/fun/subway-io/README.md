# 🚇 지하철 슬리더

승객을 태워 편성을 늘리고, 다른 열차와 부딪히지 않게 피해 다니는 **slither.io 방식의 지하철 게임**입니다.
지렁이 대신 지하철 열차가 달리고, 몸통이 길어질수록 편성 칸수가 늘어납니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/fun/subway-io/**

## 진짜 지하철처럼 보이게

캔버스로 직접 그린 화면에 실제 서울 지하철의 특징을 담았습니다.

| 요소 | 어떻게 보이나 |
|---|---|
| **편성** | 동그란 몸통이 아니라 **네모난 차량**이 줄줄이 이어집니다. 맨 앞·맨 뒤는 운전실이 있는 **선두차**, 가운데는 객차입니다 |
| **연결 통로** | 차량과 차량 사이에 **주름막(幌)** 이 그려집니다 |
| **창문 · 승객** | 옆면에 줄지어 난 네모 창문. **승객을 많이 태울수록 창문 안에 사람이 더 많이 비칩니다** — 굳이 숫자를 안 봐도 상대가 얼마나 찼는지 보입니다 |
| **출입문** | 차량 한 칸마다 **출입문 4개**. 가운데 여닫이 이음선까지 있습니다 |
| **노선색 띠** | 실제 전동차처럼 차체 옆면을 **노선색 띠**가 지나갑니다 (은색 스테인리스 차체 + 노선색 띠) |
| **행선지 표시기** | 선두차 앞쪽에 `급행 강남행` 같은 **LED 전광판**. 등급도 여기 같이 뜹니다 |
| **선두차 얼굴** | 앞유리 · 전조등(흰색) / 맨 뒤 칸은 **후미등(빨간색)** |
| **지붕** | 지붕 마루를 따라 **냉방장치**가 얹혀 있습니다 |
| **역** | **승강장 + 노란 점자블록(안전선) + 스크린도어**, 그리고 흰 바탕에 굵은 한글 · 작은 영문 · 노선색 동그라미 안 역번호가 들어간 **역명판** |
| **미니맵** | 고른 노선의 **실제 모양**을 그대로 축소해 보여줍니다 (해안선·강까지). 왼쪽 위에 어느 노선 지도인지 표시 |

노선색은 실제 값을 그대로 씁니다 (1호선 `#0052A4`, 2호선 `#00A84D`, 3호선 `#EF7C1C`, 4호선 `#00A5DE`, 5호선 `#996CAC`, 6호선 `#CD7C2F`, 7호선 `#747F00`, 8호선 `#E6186C`, 9호선 `#BDB092` …).

## 🗺️ 배경은 진짜 지도입니다

노선을 고르면 **그 노선의 실제 모양**이 배경에 깔리고, **실제 역 이름·역번호**가 붙은 역명판이 진짜 위치에 섭니다.
한강·낙동강 같은 강과 서해·남해 **해안선**도 실제 좌표 그대로입니다. 부산1호선을 고르면 부산 지도, 대구1호선을 고르면 대구 지도가 됩니다.

### 도로·공원·산·동 이름까지 (구글 지도 야간 모드 느낌)

선로 밖이 캄캄해서 심심하다는 이야기가 있어, **배경을 실제 지도로 채웠습니다.** 전부 진짜 위치입니다.

| 층 | 무엇이 | 어떻게 보이나 |
|---|---|---|
| 땅 | 경계 원 안쪽 | 짙은 남색 바닥 (선로 끝 밖은 그대로 캄캄) |
| 물 | 호수 · 넓은 강 | 파란 면 + 조금 밝은 물가선 |
| 녹지 | 공원(2ha↑) · 산림(26ha↑) · 묘지 · 운동장 | 어두운 초록 면 |
| 도로 | 고속도로 · 국도 | 굵은 선 + 가운데 밝은 속심 (지도처럼 두 겹) |
| 도로 | 주요도로(primary) · 간선도로(secondary) | 중간 · 얇은 선 |
| 글씨 | 시 · 읍 · 동 이름 2,000여 개 | 줌에 상관없이 **화면에서 같은 크기**로, 겹치면 큰 지명이 우선 |

- 배경 자료는 `map-bg.js`(약 550KB, gzip 290KB)에 따로 담았습니다. 좌표는 **구글 polyline 인코딩(1e-4°≈11m)** 으로 압축해 원본의 1/200 크기입니다.
- **`map-bg.js` 가 없어도(오프라인·파일 누락) 게임은 예전 배경으로 그대로 돌아갑니다** — 그때는 옛 격자무늬가 다시 나옵니다.
- ⚡ 배경은 절대 움직이지 않으므로 **화면보다 1.5배 넉넉한 범위를 오프스크린 캔버스에 한 번 구워 두고**, 매 프레임에는 `drawImage` 한 번만 합니다. 카메라가 구운 범위를 벗어나거나 줌이 6% 넘게 달라질 때만 다시 굽습니다. (매 프레임 벡터로 다 그렸을 때는 수도권 노선에서 10~25ms가 나와 60fps가 깨졌습니다. 지금은 배경이 있으나 없으나 프레임 시간이 같습니다.)
- 도로·녹지·물은 노선을 고르는 순간 **520px 격자 칸마다 `Path2D` 로 미리 구워** 둡니다.

- 자료: **OpenStreetMap** (© OpenStreetMap contributors, **ODbL 1.0**). Overpass API 로 받아 Douglas-Peucker 로 단순화한 뒤 `map-ko.js`(약 110KB)·`map-bg.js`(약 550KB)에 담았습니다.
- 위경도를 그대로 쓰면 가로가 눌리므로 경도에 `cos(위도)`를 곱하는 **정거원통도법**으로 폅니다. 크기는 "중심에서 가장 먼 점"을 기준으로 맞춰, 대각선으로 뻗은 1·4호선도 원형 경계를 넘지 않습니다.
- **달리는 규칙은 그대로입니다.** 선로 위를 따라가야 하는 게 아니라 예전처럼 자유롭게 다닙니다 — 지도는 배경일 뿐입니다.
- 봇 열차의 행선지도 그 노선의 진짜 역 이름에서 뽑습니다.
- 온라인 대결에서는 두 사람이 서로 다른 노선을 골랐을 수 있으므로, **지도로 쓸 노선은 공유 시드로 하나 뽑아** 양쪽이 똑같은 지도를 봅니다.
- `map-ko.js` 를 못 읽어도(오프라인·파일 누락) 게임은 **예전 방식(가상 노선도 + 가상 역 이름)으로 그대로** 돌아갑니다.

## 열차 고르기

시작 전 두 단계로 내 열차를 정합니다.

**1단계 — 노선 18종** (실제 노선색 그대로)

1~9호선 · 신분당선 · 공항철도 · 경의중앙선 · 수인분당선 · 우이신설선 · GTX-A · 인천1호선 · 부산1호선 · 대구1호선

**2단계 — 열차 등급 7종**

| 등급 | 겉모습 | LED 표시 |
|---|---|---|
| 일반열차 | 노선색 띠만 두른 기본 전동차 | `강남행` |
| 급행열차 | 노선색 띠 아래 **빨간 줄** 하나 더 | `급행 강남행` |
| 특급열차 | 노선색 띠 아래 **금색 줄** | `특급 강남행` |
| ITX-새마을 | 밝은 차체 · **큰 창** · 붉은 줄 | `ITX 강남행` |
| KTX | 은색 차체에 **유선형 앞머리** | `KTX 강남행` |
| 무궁화호 | 크림빛 차체 · **작은 창**이 촘촘 | `무궁화 강남행` |
| 광역급행 | **각진 쐐기형 전면부** · 하늘색 줄 | `광역급행 강남행` |

> **등급은 겉모습만 다릅니다.** 속도 · 회전력 · 성장 속도는 7종 모두 완전히 동일해서, 어떤 열차를 골라도 유불리가 없습니다.

## 규칙

- 바닥에 흩어진 **승객**을 머리로 지나가며 태웁니다. 승객 5명당 편성이 1칸씩 늘어납니다 (기본 4칸 → **최대 100칸**).
  44칸을 넘어서면 **승객 4명당 1칸**으로 조금 더 빨리 길어집니다. 100칸을 채우려면 승객 424명이 필요합니다.
- **내 머리가 다른 열차의 차량에 닿으면 탈선**(게임 오버)입니다.
- 반대로 다른 열차가 내 몸통에 부딪히면 그 열차가 탈선하고, **태우고 있던 승객이 선로에 쏟아집니다.** 이걸 주워 담는 게 가장 빠르게 크는 방법입니다.
- 자기 몸통에는 부딪히지 않습니다. 마음껏 감아도 됩니다.
- 붉은 점선 바깥은 선로 끝입니다. 넘어가면 즉시 탈선합니다.
- **편성이 길어질수록 회전이 무거워집니다.** 짧을 때처럼 급하게 꺾이지 않으니 미리 돌기 시작해야 합니다.

## ⏱️ 점점 빨라집니다 (난이도)

출발하고 **25초마다 속도 단계(Lv.)가 한 칸씩** 올라가고, 그때마다 **온 세상이 7.5%씩 빨라집니다.** AI 열차도 같이 빨라집니다.
최고는 **Lv.12**(약 4분 35초 뒤)로 처음의 **1.83배** 속도입니다. 지금 단계는 왼쪽 위 `속도 Lv.` 에 뜨고, 올라갈 때마다 화면 가운데에 알려줍니다.

> 빨라지면 회전 속도도 같이 올라가서 아예 못 도는 일은 없지만, 회전 반경은 조금씩 커집니다. 오래 버틸수록 미리미리 꺾어야 합니다.

## 🎁 아이템

선로 위에 **❓ 상자**가 항상 7개쯤 떠 있습니다. **먹기 전에는 무엇인지 알 수 없습니다** — 전부 똑같이 생긴 물음표 상자라서, 먹는 순간에야 정체가 화면에 뜹니다.
**내가 먹은 것만 효과가 있고, AI 열차는 아이템에 반응하지 않습니다.** 효과가 걸려 있는 동안 화면 아래쪽에 남은 시간이 표시되고, 같은 걸 또 먹으면 시간이 더해집니다(최대 2배까지).

**좋은 것 4가지**

| 아이템 | 효과 | 지속 |
|---|---|---|
| 🐢 **감속** | 속도 0.62배 — 느려지는 대신 **더 좁게 돌 수 있어** 위험한 구간을 빠져나가기 좋습니다 | 9초 |
| ⚡ **가속** | 속도 1.5배. 승객은 안 내립니다(부스터와 달리 공짜) | 7초 |
| 🛡️ **무적** | 부딪혀도 안 죽습니다. 오히려 **뚫고 지나가며 상대를 격파**하고, 선로 끝(붉은 점선)에 닿으면 죽지 않고 안쪽으로 튕겨 들어옵니다 | 8초 |
| 🧲 **자석** | 승객을 끌어당기는 범위가 **3.4배**로 넓어져 지나가기만 해도 쓸어 담습니다 | 10초 |

**함정 2가지** (좋은 것보다 덜 나옵니다 — 함정이 나올 확률은 전체의 약 5분의 1)

| 아이템 | 효과 | 지속 |
|---|---|---|
| 🧊 **정지** | 열차가 **완전히 멈춥니다.** 방향은 계속 돌릴 수 있으니 풀리는 순간 어디로 튈지 미리 잡아 두세요. 멈춰 있는 동안 다른 열차가 내 머리를 밟고 지나가면 탈선입니다 | 10초 |
| 💸 **승객 이탈** | 태운 승객이 **초당 2~3명씩 내려서** 선로에 떨어집니다. 편성도 같이 짧아지지만, 되돌아가서 다시 주우면 되찾을 수 있습니다 | 12초 |

🐢 감속과 ⚡ 가속은 서로를 지웁니다(가속 중에 감속을 먹으면 가속이 풀립니다). 미니맵에는 위치만 흰 점으로 보이고, 역시 정체는 알려주지 않습니다.

## 부스터

가속하면 속도가 약 1.8배가 되지만 **승객이 조금씩 내립니다**(초당 4~5명). 승객이 6명 이하로 남으면 가속이 걸리지 않습니다.
상대 앞을 가로막으러 갈 때나 위험 구간을 빠져나올 때만 쓰는 게 좋습니다.

## 상대 열차

AI 열차 11대가 함께 달립니다. 이 중 절반 정도는 **'사냥꾼' 성향**이라, 자기보다 작은 열차를 발견하면 진행 방향 앞을 가로막으러 옵니다.
정면에서 다가오는 열차가 갑자기 가속하면 앞을 막으려는 신호입니다.

## 기술 메모

- HTML 한 장 + 지도 데이터 한 장(`map-ko.js`), 캔버스 2D. 외부 라이브러리·외부 이미지 없음 (차량·역·지도 전부 코드로 그림)
- 몸통은 이동 거리 누적값이 담긴 경로 배열을 이분탐색으로 샘플링해 그립니다
- **차량 스프라이트 캐시** — 차량 한 칸(등급 × 노선색 × 선두/객차/후미 × 혼잡도)을 오프스크린 캔버스에 딱 한 번만 그려두고, 매 프레임에는 `drawImage` 한 번씩만 합니다. 44칸 편성이 12대여도 렌더링이 가벼운 이유
- **LOD(거리별 상세도)** — 화면에서 차량 한 칸이 17px 이상이면 창문·출입문·승객·LED까지, 그보다 작으면 창 밴드만, 7.5px 아래로 내려가면 노선색 막대 하나로 그립니다
- **화면 밖 컬링** — 열차 단위뿐 아니라 **차량 한 칸 단위**로 화면 밖이면 건너뜁니다
- 측정: **100칸 편성**을 포함한 열차 12대가 동시에 달리는 상태에서 한 프레임 계산이 평균 **0.4ms** — 1280×800, 390×844(모바일) 둘 다 60fps 여유
- **충돌 판정은 차량 중심이 아니라 경로를 일정 간격으로 샘플링한 원들**로 합니다. 차량이 길어져도 틈 사이로 뚫고 지나가는 일이 없습니다
- 최고 기록만 `localStorage`에 저장하며, 저장이 막힌 환경에서는 메모리 저장으로 자동 대체됩니다
- Node에서 게임 로직을 그대로 5,000프레임 시뮬레이션해 검증했습니다 — 등급 7종의 주행 결과 완전 일치(밸런스 동일), 충돌 샘플 연속성, 자충돌 불가, 부스터 승객 소모, 성장·사망·리필 정상 동작

## 🌐 친구랑 온라인 대결

시작 화면의 **🌐 친구랑 온라인 대결** 버튼으로 방을 만들거나, 친구가 알려준 **4글자 방 코드**를 넣어 입장한다.
두 사람은 같은 시드로 **완전히 똑같은 판**을 받아 각자 플레이하고, 위쪽 VS 바에서 상대 점수가 실시간으로 보인다.
서버는 없다 — 브라우저끼리 직접 연결(WebRTC/P2P)하고, 연결 중개만 PeerJS 공개 서버를 쓴다. 공용 코드는 `common/versus.js`.

같은 맵에서 승객 수로 겨룬다. 상대 열차는 👻 유령으로 보이기만 하고 부딪히지 않는다. AI 열차는 출발할 때만 같고 그 뒤로는 각자 화면에서 따로 움직인다.
