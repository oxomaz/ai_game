# 🚇 지하철 슬리더

승객을 태워 편성을 늘리고, 다른 열차와 부딪히지 않게 피해 다니는 **slither.io 방식의 지하철 게임**입니다.
지렁이 대신 지하철 열차가 달리고, 몸통이 길어질수록 편성 칸수가 늘어납니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/fun/subway-io/**

## 열차 고르기

시작 전 두 단계로 내 열차를 정합니다.

**1단계 — 노선 18종** (실제 노선색 그대로)

1~9호선 · 신분당선 · 공항철도 · 경의중앙선 · 수인분당선 · 우이신설선 · GTX-A · 인천1호선 · 부산1호선 · 대구1호선

**2단계 — 열차 등급 7종**

| 등급 | 겉모습 |
|---|---|
| 일반열차 | 기본 도색에 흰 벨트라인 |
| 급행열차 | 차체를 가로지르는 흰 사선 띠 |
| 특급열차 | 노란 두 줄 라인 |
| ITX-새마을 | 밝은 차체 · 큰 창 · 붉은 벨트라인 |
| KTX | 은색 차체에 유선형 앞머리 |
| 무궁화호 | 어두운 차체 · 작은 창 · 크림색 띠 |
| 광역급행 | 각진 쐐기형 전면부 · 하늘색 띠 |

> **등급은 겉모습만 다릅니다.** 속도 · 회전력 · 성장 속도는 7종 모두 완전히 동일해서, 어떤 열차를 골라도 유불리가 없습니다.

## 규칙

- 바닥에 흩어진 **승객**을 머리로 지나가며 태웁니다. 승객 5명당 편성이 1칸씩 늘어납니다 (기본 4칸 → 최대 44칸).
- **내 머리가 다른 열차의 차량에 닿으면 탈선**(게임 오버)입니다.
- 반대로 다른 열차가 내 몸통에 부딪히면 그 열차가 탈선하고, **태우고 있던 승객이 선로에 쏟아집니다.** 이걸 주워 담는 게 가장 빠르게 크는 방법입니다.
- 자기 몸통에는 부딪히지 않습니다. 마음껏 감아도 됩니다.
- 붉은 점선 바깥은 선로 끝입니다. 넘어가면 즉시 탈선합니다.
- **편성이 길어질수록 회전이 무거워집니다.** 짧을 때처럼 급하게 꺾이지 않으니 미리 돌기 시작해야 합니다.

## 부스터

가속하면 속도가 약 1.8배가 되지만 **승객이 조금씩 내립니다**(초당 4~5명). 승객이 6명 이하로 남으면 가속이 걸리지 않습니다.
상대 앞을 가로막으러 갈 때나 위험 구간을 빠져나올 때만 쓰는 게 좋습니다.

## 상대 열차

AI 열차 11대가 함께 달립니다. 이 중 절반 정도는 **'사냥꾼' 성향**이라, 자기보다 작은 열차를 발견하면 진행 방향 앞을 가로막으러 옵니다.
정면에서 다가오는 열차가 갑자기 가속하면 앞을 막으려는 신호입니다.

## 화면

- **왼쪽 위** — 현재 탑승 승객 수 · 편성 칸수 · 격파한 열차 수
- **오른쪽 위** — 실시간 순위 (상위 5대 + 내 순위)
- **오른쪽 아래** — 미니맵 (내 위치는 노란 테두리)

| 모바일 | 화면을 누른 방향으로 이동 / 왼쪽 아래 **부스터** 버튼으로 가속 |

## 기술 메모

- 단일 HTML 파일, 캔버스 2D. 외부 라이브러리 없음
- 몸통은 이동 거리 누적값이 담긴 경로 배열을 이분탐색으로 샘플링해 그립니다
- **충돌 판정은 차량 중심이 아니라 경로를 일정 간격으로 샘플링한 원들**로 합니다. 차량이 길어져도 틈 사이로 뚫고 지나가는 일이 없습니다
- 최고 기록만 `localStorage`에 저장하며, 저장이 막힌 환경에서는 메모리 저장으로 자동 대체됩니다
- Node에서 게임 로직을 그대로 5,000프레임 시뮬레이션해 검증했습니다 — 등급 7종의 주행 결과 완전 일치(밸런스 동일), 충돌 샘플 연속성, 자충돌 불가, 부스터 승객 소모, 성장·사망·리필 정상 동작
