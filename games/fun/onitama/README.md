# 🥷 오니타마 (Onitama)

5×5 판 위에서 벌이는 미니 체스. 말의 움직임은 **이동 카드**가 정하고, 한 번 쓴 카드는 **상대에게 넘어갑니다.**

## 모드

| 모드 | 설명 |
|---|---|
| 🤖 컴퓨터 | 혼자 연습. 쉬움 / 보통 / 어려움 |
| 👫 둘이서 | 한 화면에서 번갈아 두기 |
| 🌐 온라인 | 방 코드로 친구와 대결 (`common/versus.js`) |

## 규칙 / 난이도

- 각자 사부 1개(👑), 제자 4개. 손에는 이동 카드 2장, 옆에 **다음 카드** 1장이 있습니다.
- 카드의 검은 칸이 내 말, 노란 칸이 갈 수 있는 자리입니다. 방향은 **내 쪽 기준**이라 상대에게는 위아래가 뒤집혀 보입니다.
- 쓴 카드는 다음 카드 자리로 가고, 거기 있던 카드가 내 손에 들어옵니다. → **내가 쓴 카드는 다음에 상대가 씁니다.**
- 이기는 방법: 🗿 상대 사부를 잡거나(돌의 길), 🌊 내 사부가 상대 사원 칸에 도착(물의 길).
- 어떤 카드로도 움직일 수 없으면 카드 한 장만 버리고 차례를 넘깁니다.
- 컴퓨터는 알파베타(negamax) 탐색. 쉬움 1수(가끔 무작위) · 보통 3수 · 어려움 최대 8수(시간 제한 1.4초).

## 조작법

카드를 고르고 → 내 말을 누르고 → 노란 점이 찍힌 칸을 누르면 이동합니다. 마우스·터치 모두 지원합니다.

## 기록 · 배지

- 상단 프로필 칩에서 플레이어를 바꾸면 기록이 사람별로 따로 쌓입니다 (`common/profile.js`).
- 기록은 **모드별로 따로** 저장됩니다: `컴퓨터 · 어려움`, `둘이서`, `온라인 대결`. 점수는 **이겼을 때 남은 내 말 수**입니다.
- 배지: 🥷 `oni-win`(컴퓨터에게 첫 승) · 👑 `oni-hard`(어려움 격파) · 🏯 `oni-master`(누적 5승).

## 기술 메모

- 단일 `index.html` (외부 라이브러리 없음). 공용 `common/profile.js`, `common/versus.js`만 불러옵니다.
- 보드/카드 크기는 `fitLayout()`이 `--jg-vh`(실제 보이는 높이)와 화면 폭을 재서 `--bw`(보드) · `--cw`(카드) CSS 변수로 넣습니다.
  실제 요소 위치를 다시 재서 넘치면 줄이고 남으면 키우는 보정을 하므로, **작은 폰에서도 보드와 양쪽 카드가 한 화면에 다 들어옵니다.**
- 가로모드(높이 ≤ 430px)에서는 `.land` 클래스로 그리드를 바꿔 보드는 왼쪽, 카드·정보는 오른쪽에 둡니다.
- 클릭은 칸 요소에 직접 걸려 있어(좌표 계산 없음) 크기가 바뀌어도 어긋나지 않습니다.
- 저장은 localStorage 한 곳뿐이며, 막혀 있으면 자동으로 메모리 저장으로 대체되고 게임은 그대로 진행됩니다.
