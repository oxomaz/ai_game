# 🥷 오니타마 (카드 체스)

5×5 판 위에서 벌이는 미니 체스입니다. 보통 체스와 다른 점은 **말마다 정해진 움직임이 없다**는 것.
그 대신 손에 든 **이동 카드 2장**이 움직임을 정하고, **쓴 카드는 상대에게 넘어갑니다.**

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/fun/onitama/**

## 모드

- **🤖 컴퓨터** — 쉬움 / 보통 / 어려움 3단계
- **👫 둘이서** — 한 화면에서 번갈아 두기
- **🌐 온라인** — 방 코드로 친구와 진짜 턴제 대국

## 규칙

각자 **사부 1개(👑 금테)** 와 **제자 4개**를 가지고, 자기 쪽 맨 뒷줄에서 시작합니다.
가운데 칸이 각자의 **사원**입니다.

1. 손에 있는 **카드 2장 중 하나**를 고른다.
2. 카드에 그려진 모양대로 **내 말 하나**를 움직인다. (검은 칸 = 내 말 위치, 노란 칸 = 갈 수 있는 자리)
3. 상대 말이 있는 칸에 가면 **잡는다.** 내 말이 있는 칸에는 못 간다.
4. 쓴 카드는 **다음 카드** 자리로 가고, 거기 있던 카드가 내 손에 들어온다.
   → **내가 쓴 카드를 다음 차례에 상대가 쓰게 된다.** 이게 이 게임의 핵심.

카드 방향은 **각자 자기 쪽 기준**이라, 같은 카드도 상대에게는 위아래가 뒤집혀 보입니다.
게임 안에서는 카드를 항상 그 카드를 든 사람 기준으로 그려 줍니다.

### 이기는 방법 (둘 중 하나)

- 🗿 **돌의 길** — 상대 **사부**를 잡는다.
- 🌊 **물의 길** — 내 사부가 **상대 사원(상대 뒷줄 가운데)** 에 도착한다.

### 움직일 수 없을 때

어떤 카드로도 합법적인 이동이 없으면, 카드 **한 장만 버리고**(다음 카드와 교환) 차례를 넘깁니다.

## 카드 16종

호랑이 · 용 · 개구리 · 토끼 · 게 · 코끼리 · 거위 · 수탉 · 원숭이 · 사마귀 · 말 · 소 · 학 · 멧돼지 · 뱀장어 · 코브라
매 판 16장 중 **5장**만 뽑아 씁니다 (각자 2장 + 다음 카드 1장). 그래서 판마다 전략이 완전히 달라집니다.
누가 먼저 두는지는 **다음 카드 자리에 놓인 카드의 색**이 정합니다.

## 조작

카드를 누르고 → 내 말을 누르고 → 노란 점이 찍힌 칸을 누릅니다. 터치·마우스 모두 지원합니다.

## 기술 메모

- 단일 HTML 파일. 외부 라이브러리 없음(온라인 대결만 `common/versus.js` 사용).
- AI는 **알파베타 가지치기 negamax**. 쉬움 1수 / 보통 3수 / 어려움 8수(시간 제한 1.4초)까지 내다봅니다.
- 브라우저 저장소를 쓰지 않습니다.
- 자동 검증: 60판 AI 자가대국으로 불법 수·턴 누락·카드 중복이 없음을 확인했고, 어려움 AI는 쉬움 AI를 12전 12승 했습니다.

## 🌐 친구랑 온라인 대결

시작 화면에서 **🌐 온라인** 을 고르고 방을 만들거나, 친구가 알려준 **4글자 방 코드**로 입장합니다.
**방장이 파랑(선공 쪽), 참가자가 빨강**이며, 양쪽이 같은 시드로 똑같은 카드 5장을 받습니다.
둔 수는 그대로 상대 화면에 반영되는 **진짜 턴제**입니다.
서버는 없습니다 — 브라우저끼리 직접 연결(WebRTC/P2P)하고, 연결 중개만 PeerJS 공개 서버를 씁니다.
