# 🏃 점프맵 200

발판을 밟고 뛰어올라 목표 지점까지 도달하는 **200단계 파쿠르 점프맵**입니다.
레벨이 올라갈수록 발판이 좁아지고 간격이 멀어지며, 새로운 장치와 장애물이 하나씩 추가됩니다.

**▶ 플레이: https://oxomaz.github.io/jerry-games/games/fun/jump-map/**

## 특징

- **레벨 1 ~ 200** — 단계가 올라갈수록 난이도가 완만하게 상승합니다. 101단계부터는 새 장치가 계속 등장해요
- **첫 화면에서 닉네임 고르기** — 시작 화면에 내 닉네임 목록이 바로 보입니다. 눌러서 고르고, 입력칸에 이름을 적어 새로 만들고, `✕` 로 지웁니다(지울 땐 한 번 물어봐요). 닉네임 옆에는 **최고 도달 단계**가 함께 나옵니다
- **테마 20종** — 초원 · 사막 · 바다 … 심해 · 수정동굴 · 모래폭풍 · 블랙홀까지 10단계마다 배경이 바뀝니다
- **캐릭터 12종** — 네모 · 고양이 · 개구리 · 로봇 · 유령 · 펭귄 · 병아리 · 공룡 · 닌자 · 마법사 · 슬라임 · 별똥별
- **기록실** — 클리어 수 · 총 기록 · 최고 도달 레벨로 플레이어끼리 순위를 겨룹니다
- **체크포인트** — 긴 레벨에는 중간 깃발이 있어 죽어도 그 지점부터 다시 시작합니다
- **최고기록** — 레벨별 기록이 저장되고, 기록을 깨면 `✦ 신기록! ✦` 표시

## 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 좌 · 우 이동 | `←` `→` 또는 `A` `D` | 화면 아래 ◀ ▶ 버튼 |
| 점프 | `Space` / `↑` / `W` | ▲ 버튼 |
| 재시작 | `R` | ↺ 버튼 |
| 레벨 목록 | `ESC` | ☰ 버튼 |

점프 키를 짧게 누르면 낮게, 길게 누르면 높게 뜁니다. 발판 끝에서 살짝 늦게 눌러도 점프가 됩니다(코요테 타임).
모바일은 **가로 화면**을 권장합니다.

## 기술 메모

- 단일 HTML 파일, Canvas 기반 물리·렌더링. 캐릭터도 이미지 없이 전부 코드로 그립니다
- 레벨은 시드 기반으로 자동 생성되며, 같은 레벨은 항상 같은 맵입니다
- 발판 간격은 **점프 도달거리 공식(`reachDx`)의 90% 이내**로 제한되고, 이동 발판은 가장 불리한 위치를 기준으로 계산합니다
- 1~100단계의 물리 상수·레벨 생성 규칙은 그대로 두고, **101~200단계에만** 새 장치가 등장하도록 확장했습니다
- **200개 레벨 전부를 실제 게임 코드로 시뮬레이션해 클리어 가능 여부를 검증**했습니다. 검증기(`verify_jump.js`)는 게임의 `step()` 물리를 그대로 돌리면서 (발판번호 · 위치 · 도착 시각)을 상태로 두고 최선우선 탐색을 하기 때문에, 점멸 발판·낙석·레이저처럼 **시간에 따라 변하는 기믹의 타이밍까지 포함**해서 "실제로 건널 수 있는 순간이 존재하는지"를 확인합니다 (200/200 통과)
- 회전 가시봉은 "최대 점프로 위를 넘어갈 수 있는 팔 길이"를 계산해 제한하고, 오래 서서 기다릴 수 없는 발판(사라짐·점멸·점프대)에서 출발하는 틈에는 타이밍 장애물을 두지 않아 항상 통과 가능한 순간이 있게 했습니다
- 진행상황·기록은 `localStorage`에 저장하되, 접근이 막히면 메모리 저장으로 자동 대체되어 게임이 멈추지 않습니다

## 🌐 친구랑 온라인 대결

시작 화면의 **🌐 친구랑 온라인 대결** 버튼으로 방을 만들거나, 친구가 알려준 **4글자 방 코드**를 넣어 입장한다.
두 사람은 같은 시드로 **완전히 똑같은 판**을 받아 각자 플레이하고, 위쪽 VS 바에서 상대 점수가 실시간으로 보인다.
서버는 없다 — 브라우저끼리 직접 연결(WebRTC/P2P)하고, 연결 중개만 PeerJS 공개 서버를 쓴다. 공용 코드는 `common/versus.js`.
시작 레벨은 1 / 21 / 41 / 61 / 81 / 121 / 161 중에서 방장이 고른다. 첫 화면에서 골라둔 닉네임이 있으면 대결 로비 이름칸에 기본값으로 채워진다.

같은 코스를 동시에 달리는 레이스. 상대는 반투명 고스트로 보이고, 화면 밖이면 가장자리 화살표로 어디쯤인지 알려준다.
