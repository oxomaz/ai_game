# 👑 달무티 (The Great Dalmuti)

리처드 가필드의 보드게임 **The Great Dalmuti**를 원작 규칙 그대로 옮긴 카드 게임입니다.
브라우저만 있으면 되고, **2~10명**이 방 코드 하나로 함께 할 수 있습니다.

먼저 손의 카드를 다 털어내면 **대달무티(1등)**, 끝까지 남으면 **대농노(꼴찌)**.
다음 판에서 계급이 그대로 바뀌고, 아래 계급은 위 계급에게 **세금**을 바쳐야 합니다.

---

## 🎮 모드

| 모드 | 설명 |
|---|---|
| 혼자 하기 | 컴퓨터 1~9명과 대결 |
| 🌐 여럿이서 온라인 | 방 코드 4글자로 최대 10명. 빈 자리는 컴퓨터가 채움 |

- **컴퓨터 실력** — 쉬움 · 보통 · 어려움
- **판 수** — 3 · 5 · 10 · 20판 (원작 권장은 20판)
- **패스 규칙** — 원작(패스해도 다시 낼 수 있음) / 변형(한 번 패스하면 그 판은 쉼)

  혼자 내면 13이 되어 가장 약합니다.

## 📜 규칙

### 계급
| 자리 | 이름 |
|---|---|
| 1등 | 대달무티 👑 |
| 2등 | 소달무티 🎩 |
| 중간 | 상인 ⚖️ |
| 끝에서 2번째 | 소농노 🧺 |
| 꼴찌 | 대농노 🥔 |

3명 이하일 때는 소달무티·소농노 자리가 없습니다.

### 세금
매 판 카드를 나눈 뒤, 아래 계급이 위 계급에게 카드를 바칩니다. **동시에 교환**합니다.

- 대농노 → 대달무티: **가장 좋은(숫자가 작은) 카드 2장** / 대달무티는 아무 카드 2장을 돌려줌
- 소농노 → 소달무티: 가장 좋은 카드 1장 / 소달무티도 아무 카드 1장

### 혁명
- **광대 2장을 모두 가진 사람**은 세금을 걷기 전에 **혁명**을 선언할 수 있습니다 → 이번 판 세금 없음.
- 그 사람이 **대농노**라면 **대혁명** — 계급이 통째로 뒤집힙니다. (대농노 ↔ 대달무티)

### 카드 내기
1. **대달무티가 먼저** 같은 숫자 여러 장을 냅니다. (예: 7 세 장)
2. 다음 사람은 **같은 장수**로 **더 작은 숫자**를 내거나 패스합니다.
3. 모두가 연달아 패스하면 마지막에 낸 사람이 그 판을 가져가고, 다시 먼저 냅니다.
4. **원작에서는 패스해도 자기 차례가 돌아오면 다시 낼 수 있습니다.** (설정에서 변형 규칙 선택 가능)
5. 손을 다 털면 그 판에서 빠지고, 마지막 한 명이 남으면 판이 끝납니다.

### 점수
손을 털 때 **아직 카드를 든 사람 수만큼** 점수를 받습니다. (원작의 선택 규칙)
정한 판 수가 끝나면 합계가 가장 높은 사람이 우승합니다.

---

## 🕹️ 조작

- 손패에서 카드를 탭하면 선택됩니다. 따라가는 차례라면 **필요한 장수만큼 같은 숫자를 자동으로 채워줍니다.**
  (모자라면 광대로 채웁니다.) 다시 탭하면 선택이 풀립니다.
- 낼 수 없는 카드는 흐리게 표시됩니다.
- `내기` / `패스` 버튼으로 진행하고, `기록` 버튼으로 지금까지의 진행 내역을 볼 수 있습니다.

## 🔧 기술 메모

- 순수 HTML/CSS/JS 한 파일. 외부 라이브러리 없음 (온라인 대결만 `common/peerjs.min.js` 사용).
- 온라인은 **`common/room.js`** — 이 게임을 위해 새로 만든 **2~10명용 방 라이브러리**입니다.
  참가자는 전부 방장하고만 연결하는 **별(star) 구조**이고, 방장이 판정을 전부 맡습니다
  (**host-authoritative**). 손패가 비밀인 게임이라 시드 동기화 방식은 쓸 수 없기 때문입니다.
  방장은 자리마다 다른 화면 정보(`viewFor`)를 만들어 각자에게만 보냅니다 — 남의 손패는 전송되지 않습니다.
- 중간에 나간 사람의 자리는 컴퓨터가 이어받습니다. 방장이 나가면 게임이 끝납니다.
- 기록·배지는 `common/profile.js`(전역 `JG`). 게임 id 는 `dalmuti`.
- 자동 검사용 훅: `window.__dal` (`G` · `analyze` · `canPlay` · `enumMoves` · `botMove` · `setSpeed` 등).
  봇끼리 자가대국을 돌려 규칙 위반·무한 루프가 없는지 확인할 수 있습니다.
