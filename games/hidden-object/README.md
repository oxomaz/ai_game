# 🔍 숨은그림찾기

수십 개의 귀여운 그림이 흩뿌려진 그림판에서, 위에 제시된 **목표 그림**을 찾아 클릭하는 게임입니다.
혼자서도 할 수 있고, 한 화면에서 둘이서 버저 대결도 할 수 있습니다.

**▶ 플레이: https://oxomaz.github.io/ai_game/games/hidden-object/**

## 특징

- **매판 새로 만들어지는 그림판** — 34종의 일러스트를 SVG 코드로 직접 그립니다. 위치·크기·회전·색이 매번 새로 생성되어 같은 판이 두 번 나오지 않습니다.
- **정답은 항상 딱 하나** — 목표로 지정된 종류는 그림판에 단 하나만 등장하고, 나머지 미끼는 모두 다른 종류라 헷갈릴 일이 없습니다.
- 라운드마다 배경 테마가 바뀌고, 사운드는 Web Audio로 직접 생성합니다 (🔊 버튼으로 끄기 가능).

## 모드

### 혼자 하기

- 제한시간 안에 목표 그림을 모두 찾으면 클리어, **남은 시간 × 5점**이 보너스
- 정답 +100점 / 오답 −20점 & −3초
- 힌트는 라운드당 1번 (−40점) — 목표 칩과 그림판 위치가 함께 반짝입니다

### 둘이서 대결 (한 화면)

같은 그림판을 두 사람이 함께 보다가, 찾은 사람이 **먼저 버저를 누르고** 4초 안에 그림을 클릭합니다.
마우스가 하나뿐인 노트북에서도 제대로 대결이 되도록 만든 방식입니다.

| | 1P | 2P |
|---|---|---|
| 키보드 | `Q` | `P` |
| 터치 | 화면 아래 왼쪽 버튼 | 화면 아래 오른쪽 버튼 |

- 정답 **+100점**, 오답 **−40점**, 4초 초과 **−20점**
- 실패한 사람은 2.5초간 버저 잠금 → 상대에게 기회가 넘어갑니다
- 버저를 누르지 않고 클릭하면 무시됩니다
- 라운드마다 누가 무엇을 찾았는지 목표 칩에 `1P` / `2P` 배지로 표시

## 난이도

| 난이도 | 그림 개수 | 목표 수 | 제한시간 | 특징 |
|---|---|---|---|---|
| 쉬움 🐣 | 30 | 3 | 80초 | 크게, 거의 안 돌아감 |
| 보통 🐱 | 58 | 4 | 65초 | |
| 어려움 🔥 | 95 | 5 | 55초 | 많이 회전, 색 변화 큼 |
| 악몽 💀 | 140 | 6 | 48초 | 작고 빽빽하게, 완전 랜덤 회전 |

라운드가 진행될수록 그림 개수가 조금씩 늘어납니다. 라운드 수는 3 / 5 / 7판 중 선택.

## 조작

| 동작 | 키 |
|---|---|
| 그림 찾기 | 마우스 클릭 · 터치 |
| 1P 버저 / 2P 버저 | `Q` / `P` |
| 힌트 | `H` |
| 나가기 | `Esc` |

## 기술 메모

- 단일 HTML 파일, 외부 이미지 리소스 없음 (모든 그림이 인라인 SVG)
- 그림은 격자 지터 방식으로 배치해 고르게 흩어지면서도 자연스럽게 겹칩니다
- 클릭 판정은 각 그림에 붙은 투명 원으로 처리해 작은 그림도 잘 눌립니다
- 브라우저 저장소를 쓰지 않습니다
